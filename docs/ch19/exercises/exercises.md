# 연습문제

**연습문제 1. 로짓과 오즈**

대출 부도($Y = 1$)에 대한 로지스틱 회귀모형이 다음과 같다.

$$
\log\frac{p}{1-p} = -2.5 + 0.8\,\text{DTI} - 0.03\,\text{Credit Score}
$$

여기서 DTI는 부채상환비율, Credit Score는 FICO 점수이다.

**(a)** DTI $= 3.0$, Credit Score $= 700$인 차주의 부도확률 예측값을 계산하라.

**(b)** DTI의 계수 $0.8$을 오즈비로 해석하라.

**(c)** Credit Score $= 650$인 차주의 부도확률이 50%가 되는 DTI는 얼마인가?

??? success "풀이"
    **(a)** 주어진 대로 계산하면

    $$
    \text{logit} = -2.5 + 0.8(3) - 0.03(700) = -2.5 + 2.4 - 21 = -21.1
    $$

    $$
    \hat{p} = \frac{1}{1 + e^{21.1}} = 6.9 \times 10^{-10}
    $$

    사실상 0이다. **이 답은 모형이 잘못 설정되었다는 신호로 읽어야 한다.**

    !!! warning "계수의 척도를 확인하라"
        문제가 어디에 있는지 보자. Credit Score 항의 기여가 $-21$로 다른 모든 항을 압도한다. 계수 $-0.03$은 **점수 1점당** 로그오즈가 $0.03$ 줄어든다는 뜻인데, FICO 점수는 300–850 범위이므로 이는 터무니없이 큰 효과다. 점수 100점 차이가 로그오즈를 3만큼 바꾼다면 오즈가 20배 변한다.

        실무에서 쓰는 척도는 둘 중 하나다.

        | 해석 | 계수 | logit | $\hat{p}$ |
        |:---|---:|---:|---:|
        | 점수를 **점** 단위로, 계수 $-0.03$ (원문 그대로) | $-0.03$ | $-21.1$ | $\approx 0$ |
        | 점수를 **점** 단위로, 계수 $-0.003$ | $-0.003$ | $-2.20$ | **0.0998** |

        아래 (b), (c)는 합리적인 척도인 $-0.003$을 기준으로 푼다. 이 경우 부도확률이 약 **10.0%**로 대출 포트폴리오에서 볼 법한 값이 된다.

        **교훈:** 로지스틱 회귀에서 계수를 읽을 때는 반드시 **예측변수의 단위**와 함께 읽어야 한다. 계수 하나만 보고 "크다/작다"를 말할 수 없다.

    **(b)** $e^{0.8} = 2.2255$이다. Credit Score를 고정한 채 DTI가 1단위 증가하면 부도의 **오즈가 2.23배**가 된다(123% 증가).

    오즈비는 확률비가 아니라는 점에 주의해야 한다. 기저 확률이 낮으면 오즈비와 위험비가 비슷하지만, 기저 확률이 높으면 크게 갈라진다.

    **(c)** $p = 0.5$이면 $\text{logit} = 0$이므로

    $$
    0 = -2.5 + 0.8\,\text{DTI} - 0.003(650) \;\Longrightarrow\; 0.8\,\text{DTI} = 2.5 + 1.95 = 4.45
    $$

    $$
    \text{DTI} = 5.56
    $$

    부채가 소득의 5.56배라는 뜻으로, 현실에서는 극단적인 값이다. 신용점수 650인 차주가 부도확률 50%에 도달하려면 그 정도의 부채가 필요하다는 해석이다.

**연습문제 2. 로지스틱 회귀의 MLE**

관측 4개 $(x_1, y_1) = (1, 0)$, $(x_2, y_2) = (2, 0)$, $(x_3, y_3) = (3, 1)$, $(x_4, y_4) = (4, 1)$과 모형 $\log\frac{p}{1-p} = \beta_0 + \beta_1 x$가 주어졌다.

**(a)** 로그가능도를 $\beta_0$와 $\beta_1$의 함수로 쓰라.

**(b)** 닫힌 형태의 해가 없어 수치 최적화가 필요한 이유를 설명하라.

**(c)** 파이썬으로 $\hat{\beta}_0$과 $\hat{\beta}_1$을 구하라.

??? success "풀이"
    **(a)** $p_i = \dfrac{1}{1 + e^{-(\beta_0 + \beta_1 x_i)}}$이므로

    $$
    \ell(\beta_0, \beta_1) = \sum_{i=1}^4 \left[y_i \log p_i + (1-y_i)\log(1-p_i)\right]
    = \log(1-p_1) + \log(1-p_2) + \log p_3 + \log p_4
    $$

    **(b)** 점수방정식 $\frac{\partial \ell}{\partial \beta_0} = 0$, $\frac{\partial \ell}{\partial \beta_1} = 0$에 $p_i$가 들어가는데, $p_i$는 $\beta$의 비선형 함수이다. 따라서 방정식을 대수적으로 풀 수 없다.

    **(c)**

    ```python
    import numpy as np
    from sklearn.linear_model import LogisticRegression

    X = np.array([[1], [2], [3], [4]])
    y = np.array([0, 0, 1, 1])

    model = LogisticRegression(penalty=None, solver='lbfgs')
    model.fit(X, y)
    print(model.intercept_[0], model.coef_[0][0])
    ```

    !!! danger "이 자료는 완전분리(complete separation)를 일으킨다"
        $x \le 2$이면 $y = 0$, $x \ge 3$이면 $y = 1$로 **두 부류가 완벽히 분리된다.**

        이때 로그가능도는 최댓값을 갖지 않는다. $\beta_1 \to \infty$로 보내면서 절편을 맞추면 가능도가 1에 한없이 가까워지기 때문이다. 즉 **MLE가 존재하지 않는다.**

        수치 최적화기는 오류를 내지 않고 그냥 큰 값을 반환한다. `penalty=None`으로 두면 $\hat{\beta}_1$이 반복 횟수 제한에 걸릴 때까지 계속 커진다. 정칙화를 켜 두면(sklearn의 기본값) 유한한 값이 나오지만 그것은 MLE가 아니라 벌점 추정값이다.

        실무에서 완전분리를 만나면 다음을 고려한다. 벌점 가능도(Firth 보정), 능형 정칙화, 또는 자료를 더 모으는 것이다. 무엇보다 **계수가 비정상적으로 크고 표준오차가 거대하면 분리를 의심해야 한다.**

**연습문제 3. 모형 평가**

스팸 분류기가 이메일 1000개의 검정집합에서 다음 혼동행렬을 냈다.

|  | 스팸으로 예측 | 정상으로 예측 |
|---|---|---|
| **실제 스팸** | 85 | 15 |
| **실제 정상** | 30 | 870 |

**(a)** 정확도, 정밀도, 재현율, 특이도, F1 점수를 계산하라.

**(b)** 스팸을 놓치는 비용이 오탐 비용의 3배라면 분류 문턱을 낮춰야 하는가 높여야 하는가?

**(c)** 위양성률(FPR)은 얼마인가?

??? success "풀이"
    **(a)** TP $= 85$, FN $= 15$, FP $= 30$, TN $= 870$

    | 지표 | 계산 | 값 |
    |:---|:---|---:|
    | 정확도 | $(85+870)/1000$ | 0.955 |
    | 정밀도 | $85/(85+30)$ | 0.739 |
    | 재현율 | $85/(85+15)$ | 0.850 |
    | 특이도 | $870/(870+30)$ | 0.967 |
    | F1 | $2 \times 0.739 \times 0.850/(0.739+0.850)$ | 0.791 |

    **(b)** 스팸을 놓치는 것(FN)이 더 비싸므로 문턱을 **낮춰** 재현율을 높이고(스팸을 더 많이 잡고) 위양성이 늘어나는 것을 감수해야 한다.

    **(c)** FPR $= \text{FP}/(\text{FP}+\text{TN}) = 30/900 = 0.033$

    !!! note "정확도 95.5%에 속지 말 것"
        이 자료는 스팸이 10%뿐이다. 모든 메일을 "정상"으로 예측하는 무의미한 분류기도 **정확도 90%**를 얻는다. 정확도 $0.955$는 그 기준선보다 $5.5$%p 나은 것에 불과하다.

        불균형 자료에서는 정확도 대신 정밀도·재현율, F1, 또는 PR 곡선 아래 면적을 봐야 한다.

**연습문제 4. ROC와 AUC**

**(a)** 웬만한 분류기의 ROC 곡선이 대각선 위에 놓이는 이유를 설명하라.

**(b)** 어떤 모형의 AUC가 0.85이다. 확률적 해석을 제시하라.

**(c)** 모형 A의 AUC가 0.92, 모형 B가 0.88이다. 언제나 모형 A가 배포에 더 낫다고 결론지을 수 있는가? 이유는?

??? success "풀이"
    **(a)** 대각선은 무작위 분류에 해당한다(모든 문턱에서 TPR $=$ FPR). 웬만한 분류기는 양성에 음성보다 높은 확률을 부여하므로, 어떤 FPR에서든 무작위 추측보다 높은 TPR을 달성한다.

    **(b)** 양성 하나와 음성 하나를 무작위로 뽑았을 때, 모형이 양성 쪽에 더 높은 예측확률을 부여할 확률이 85%이다.

    **(c)** 반드시 그렇지는 않다. AUC는 **모든 문턱에 걸친** 성능을 요약한 값이다. 실제 응용에서 쓰는 특정 작동 문턱에서는 모형 B가 더 나을 수 있다.

    또한 불균형 자료에서는 PR-AUC가 더 유용한 정보를 준다. AUC는 오분류 비용의 차이도 반영하지 못한다. 연습문제 3처럼 FN이 FP보다 3배 비싼 상황이라면, 두 모형을 그 비용 구조 아래에서 비교해야 한다.
