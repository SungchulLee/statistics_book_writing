# Brown-Forsythe 검정 (scipy)

## 개요

Brown-Forsythe 검정은 여러 집단의 분산 동일성을 평가하는, Bartlett 검정의 로버스트 대안이다. Levene 검정의 변형으로 중심화에 집단평균 대신 집단중앙값을 써서 정규성 이탈에 저항한다. SciPy에서는 `scipy.stats.levene`에 `center='median'` 인자를 주어 쓴다.

---

## 1. 검정 설정

크기 $n_1, \ldots, n_k$인 독립 집단 $k$개가 주어졌을 때 가설은

$$
H_0 : \sigma_1^2 = \sigma_2^2 = \cdots = \sigma_k^2 \quad \text{대} \quad H_1 : \sigma_i^2 \text{이 모두 같지는 않다}
$$

---

## 2. 작동 방식

Brown-Forsythe 검정은 원래의 관측값을 집단중앙값으로부터의 절대편차로 변환한다.

$$
z_{ij} = |x_{ij} - \tilde{x}_i|
$$

여기서 $\tilde{x}_i$는 집단 $i$의 중앙값이다. 그런 다음 변환값 $z_{ij}$에 일원분산분석 $F$ 검정을 수행한다.

$$
W = \frac{\sum_{i=1}^{k} n_i (\bar{z}_{i\cdot} - \bar{z}_{\cdot\cdot})^2 \,/\, (k - 1)}{\sum_{i=1}^{k}\sum_{j=1}^{n_i} (z_{ij} - \bar{z}_{i\cdot})^2 \,/\, (N - k)}
$$

여기서 $\bar{z}_{i\cdot}$은 집단 $i$의 변환값 평균, $\bar{z}_{\cdot\cdot}$은 전체평균, $N = \sum n_i$이다. $H_0$ 아래에서 $W$는 근사적으로 $F(k-1, N-k)$이다.

---

## 3. 왜 중앙값인가

원래의 Levene 검정은 중심화에 집단 **평균**을 쓴다($z_{ij} = |x_{ij} - \bar{x}_i|$). Brown과 Forsythe(1974)는 평균을 중앙값으로 바꾸면 다음과 같은 검정이 됨을 보였다.

- 치우쳤거나 꼬리가 두꺼운 분포에서 올바른 제1종 오류율을 유지한다.
- 정규성 아래에서 Levene 검정에 견줄 만한 검정력을 갖는다.
- 중앙값이 위치의 로버스트 추정량이므로 이상점의 영향을 덜 받는다.

세 번째 항목이 왜 중요한지는 기계적으로 따라가 보면 분명하다. 아래 보기의 첫 집단 `g1 = [12, 15, 14, 10, 13, 14, 12, 11]`에서 값 하나만 $10 \to 34$로 바꾸어 보자.

![이상점 하나가 중심과 모든 절대편차에 미치는 영향](./img/median_centering_mechanism.png)

왼쪽에서 두 중심의 반응이 갈린다. 평균은 $12.62$에서 $15.62$로 **3만큼** 끌려가 원자료 여덟 개 중 여섯 개보다 오른쪽에 자리 잡는다. 더 이상 이 자료의 중심이 아니다. 중앙값은 $12.5$에서 $13.5$로 한 칸 움직였을 뿐이다. 중앙값이 옮겨 가려면 순서상 이웃한 값까지만 가면 되기 때문이며, 이것이 붕괴점 50%의 실제 모습이다.

오른쪽이 그 결과다. 이상점 하나 때문에 중심이 3만큼 밀리면, **이상점이 아닌 나머지 일곱 값의 절대편차까지 전부 달라진다.** 값 13의 편차는 중앙값 기준 $0.5$인데 평균 기준으로는 $2.62$다. 값 11은 $2.5$ 대 $4.62$다. 오염된 관측값은 하나인데 오염된 편차는 여덟 개가 되는 셈이다.

이 전파가 검정 결과를 바꾼다. 세 집단에 대해 실제로 돌려 보면 오염 전에는 평균 중심 $p = 0.3444$, 중앙값 중심 $p = 0.3489$로 사실상 같다. 오염 후에는 평균 중심이 $p = 0.1593$으로 절반 이하로 떨어지는데 중앙값 중심은 $p = 0.5276$으로 오히려 올라간다. **평균 중심 판은 "집단 1의 산포가 크다"는 쪽으로 끌려가고, 중앙값 중심 판은 흔들리지 않는다.**

한 가지 덧붙일 것이 있다. 중앙값 중심에서 이상점 **자신의** 편차는 $20.5$로 평균 중심의 $18.38$보다 오히려 크다. 브라운–포사이드가 이상점을 무시하는 것이 아니라, 이상점의 영향을 **그 한 점에 가두어** 나머지 관측값이 오염되지 않게 한다는 뜻이다.

    **(1) $g_3 = g_1 + 20$ 이다.** 여덟 쌍을 하나씩 빼 보면 전부 $20$ 이다. 평행이동은 중심(평균이든 중앙값이든)도 같이 $20$ 만큼 옮기므로 **절대편차가 글자 그대로 같아진다.**

    $$
    z_{3j} = \lvert (x_{1j}+20) - (c_1 + 20)\rvert = \lvert x_{1j} - c_1\rvert = z_{1j}
    $$

    그러므로 $\bar z_3 = \bar z_1$, $S_3 = S_1$ 이고, **세 집단 문제가 두 집단의 정보로 줄어든다.**

    **닫힌 꼴.** $\bar z_1 = \bar z_3 = a$, $\bar z_2 = b$, $n_i = 8$, $N = 24$, $k = 3$ 이라 쓰자. 전체평균이 $\bar z = (2a+b)/3$ 이므로 세 집단의 편차가

    $$
    a - \bar z = \frac{a-b}{3}\;(\text{두 번}), \qquad b - \bar z = \frac{2(b-a)}{3}
    $$

    이고 집단간 제곱합은

    $$
    \mathrm{SS}_{\text{between}} = 8\left[2\cdot\frac{(a-b)^2}{9} + \frac{4(a-b)^2}{9}\right] = 8(a-b)^2\cdot\frac69 = \frac{16}{3}(a-b)^2
    $$

    이다. 집단내 제곱합은 $S_1 + S_2 + S_3 = 2S_1 + S_2$ 이므로

    $$
    W = \frac{(N-k)\,\mathrm{SS}_{\text{between}}}{(k-1)\,\mathrm{SS}_{\text{within}}}
    = \frac{21 \cdot \frac{16}{3}(a-b)^2}{2\,(2S_1+S_2)}
    = \frac{56\,(a-b)^2}{2S_1 + S_2}
    $$

    를 얻는다. **네 수만 알면 $W$ 가 정해진다.**

    **(2) 분자가 왜 같은가.** 분자는 $a$ 와 $b$ 로만 만들어지므로, 두 중심에서 $a$ 와 $b$ 가 같으면 분자도 같다. 두 가지 우연이 겹쳐 그렇게 된다.

    *$b$ 가 같은 까닭.* $g_2$ 를 정렬하면 $18, 19, \ldots, 25$ 로 연속한 여덟 정수라 **평균과 중앙값이 둘 다 $21.5$** 다. 중심이 같으니 $z_{2j}$ 자체가 같고 $b$ 도 $S_2$ 도 같다.

    *$a$ 가 같은 까닭.* 이쪽은 더 섬세하다. $g_1$ 의 중앙값은 $12.5$, 평균은 $12.625$ 로 **다르다.** 그런데 $g(c) = \sum_j \lvert x_{1j} - c\rvert$ 는 볼록·조각선형이고 $n$ 이 짝수이므로 최소점이 한 점이 아니라 구간 $[x_{(4)}, x_{(5)}] = [12, 13]$ 이다(11.5절 보기 1 의 유도). **평균 $12.625$ 가 그 구간 안에 든다.** 그러므로

    $$
    \sum_j \lvert x_{1j} - 12.5\rvert = \sum_j \lvert x_{1j} - 12.625\rvert = 11
    $$

    이고 $a = 11/8 = 1.375$ 가 두 중심에서 같다. 개별 $z_{1j}$ 는 다른데 **합이 같다.**

    **그러므로 차이는 분모에만 남는다.** $S_1$ 은 $z_{1j}$ 의 산포이므로 개별 값이 바뀌면 달라진다. 두 $W$ 의 비는

    $$
    \frac{W_{\text{평균}}}{W_{\text{중앙값}}} = \frac{2S_1^{(\text{중앙값})} + S_2}{2S_1^{(\text{평균})} + S_2}
    $$

    로 **분모만의 비**가 된다.

    **확인한다.**

    ```python
    import numpy as np
    from scipy.stats import levene

    # 세 집단의 평균은 크게 다르지만 퍼짐은 거의 같다.
    g1 = np.array([12, 15, 14, 10, 13, 14, 12, 11], dtype=float)
    g2 = np.array([22, 25, 20, 18, 24, 23, 19, 21], dtype=float)
    g3 = np.array([32, 35, 34, 30, 33, 34, 32, 31], dtype=float)

    print("variances:", [round(np.var(g, ddof=1), 4) for g in (g1, g2, g3)])

    # scipy 에는 brown_forsythe 라는 함수가 따로 없다. levene 에
    # center='median' 을 주는 것이 곧 Brown-Forsythe 이고, 이것이 기본값이다.
    W, p = levene(g1, g2, g3, center='median')
    print(f"Brown-Forsythe W = {W:.6f}, p-value = {p:.6f}")

    W_mean, p_mean = levene(g1, g2, g3, center='mean')
    print(f"Levene (mean)  W = {W_mean:.6f}, p-value = {p_mean:.6f}")

    # (1) g3 가 g1 의 평행이동인가.
    print(f"\ng3 - g1 = {g3 - g1}   ->  g3 = g1 + {int((g3 - g1)[0])} 인가: "
          f"{np.all(g3 - g1 == 20)}")

    # (1)(2) 닫힌 꼴 W = 56 (zbar1 - zbar2)^2 / (2 S1 + S2) 를 두 중심에서 조립한다.
    print(f"\n{'중심':>7}{'zbar1':>9}{'zbar2':>9}{'S1':>9}{'S2':>9}"
          f"{'분자 56(dz)^2':>15}{'분모 2S1+S2':>13}{'W':>11}")
    for name, c in [("median", np.median), ("mean", np.mean)]:
        z1, z2, z3 = (np.abs(g - c(g)) for g in (g1, g2, g3))
        assert np.array_equal(z1, z3)          # g3 = g1 + 20 이므로 편차가 같다
        a, b = z1.mean(), z2.mean()
        S1 = ((z1 - a) ** 2).sum()
        S2 = ((z2 - b) ** 2).sum()
        num, den = 56 * (a - b) ** 2, 2 * S1 + S2
        print(f"{name:>7}{a:>9.4f}{b:>9.4f}{S1:>9.4f}{S2:>9.4f}"
              f"{num:>15.5f}{den:>13.4f}{num / den:>11.6f}")

    # 왜 zbar1 이 두 중심에서 같은가. 중앙값이 sum|y-c| 를 최소화하는 구간을 본다.
    s = np.sort(g1)
    print(f"\ng1 정렬 = {s}")
    print(f"  중앙값 = {np.median(g1):.3f},  평균 = {g1.mean():.3f}")
    print(f"  최소화 구간 [x_(4), x_(5)] = [{s[3]:.0f}, {s[4]:.0f}] 에 평균이 드는가: "
          f"{s[3] <= g1.mean() <= s[4]}")
    for c in (s[3], np.median(g1), g1.mean(), s[4]):
        print(f"    c = {c:7.3f}  ->  sum|g1 - c| = {np.abs(g1 - c).sum():.6f}")
    print(f"\ng2 의 평균 {g2.mean():.3f} = 중앙값 {np.median(g2):.3f} 인가: "
          f"{g2.mean() == np.median(g2)}")

    # (2) 분자가 같으니 두 W 의 비는 분모의 비와 같아야 한다.
    print(f"\nW(mean)/W(median) = {W_mean / W:.6f}")
    print(f"분모의 비 19.75/19.50 = {19.75 / 19.50:.6f}")
    ```

    **닫힌 꼴이 SciPy 와 소수 여섯째 자리까지 맞는다.** 네 수 $(a, b, S_1, S_2)$ 만으로 조립한 $W$ 가 중앙값 쪽 $1.107595$, 평균 쪽 $1.121795$ 로 `levene` 의 값과 같다. 손으로 따라가면

    $$
    W_{\text{중앙값}} = \frac{56\,(1.375 - 2.0)^2}{2(4.875)+10} = \frac{21.875}{19.75} = 1.107595
    $$

    이다. `assert np.array_equal(z1, z3)` 가 통과한 것이 $g_3 = g_1 + 20$ 의 결과를 확인해 준다.

    **(2)의 예측이 모두 맞는다.** 분자가 두 중심에서 $21.87500$ 으로 **완전히 같고**, $S_2 = 10.0000$ 도 같다. 달라진 것은 $S_1$ 하나, $4.8750$ 대 $4.7500$ 뿐이다. 그래서 분모가 $19.75$ 대 $19.50$ 이 되고 $W$ 의 비가 $1.012821$, 분모의 비 $19.75/19.50 = 1.012821$ 과 소수 여섯째 자리까지 같다.

    **$\sum_j \lvert g_1 - c\rvert$ 가 네 점에서 모두 정확히 $11$ 이라는 줄이 (2)의 핵심이다.** $c = 12,\ 12.5,\ 12.625,\ 13$ 어디서 재도 같다. 짝수 표본에서 최소점이 구간이라는 사실이 눈에 보이는 꼴이며, 평균이 그 구간 안에 들어 있었다는 우연 덕분에 분자가 보존되었다. **평균이 $[12, 13]$ 밖으로 나가면 $a$ 가 커지고 분자까지 달라진다.**

    **$S_1$ 쪽이 중앙값에서 더 크다는 것도 눈여겨볼 만하다.** $4.875 > 4.750$ 이다. 중앙값은 $z$ 의 **합**을 최소화하지만 $z$ 의 **산포**는 최소화하지 않으며, 여기서는 오히려 키웠다. 그 결과 중앙값 판의 $W$ 가 더 작고 $p$ 값이 더 크다($0.348894$ 대 $0.344444$). 로버스트성의 대가인 검정력 손실이 이 자료에서는 $p$ 값 소수 셋째 자리만큼이다.

---

## 4. 해석

- $W$ 통계량이 크면($p$값이 작으면) $H_0$을 기각하고 집단분산이 모두 같지는 않다고 결론짓는다.
- 이 세 집단은 주로 위치가 다르고 산포는 비슷하므로 $W$가 작고 $p$가 크게 나온다. 등분산을 기각하지 못한다.
- 자료의 정규성이 불확실할 때 등분산성 검정의 권장 기본값이 Brown-Forsythe 검정이다.

표본분산이 $2.84$, $6.00$, $2.84$로 최대·최소 비가 $2.1$인데도 유의하지 않다. 각 집단 $n = 8$로는 검정력이 매우 낮기 때문이다.

    집단중앙값: $\tilde{x}_1 = 4$, $\tilde{x}_2 = 7$.

    중앙값으로부터의 절대편차:

    - 집단 1: $z_{11} = |2-4| = 2$, $z_{12} = |4-4| = 0$, $z_{13} = |6-4| = 2$
    - 집단 2: $z_{21} = |1-7| = 6$, $z_{22} = |5-7| = 2$, $z_{23} = |9-7| = 2$, $z_{24} = |13-7| = 6$

    집단평균: $\bar{z}_1 = (2+0+2)/3 = 4/3$, $\bar{z}_2 = (6+2+2+6)/4 = 4$.

    전체평균: $\bar{z} = (2+0+2+6+2+2+6)/7 = 20/7 = 2.8571$.

    집단간 제곱합:

    $$
    \text{SS}_B = 3\left(\tfrac{4}{3} - \tfrac{20}{7}\right)^2 + 4\left(4 - \tfrac{20}{7}\right)^2 = 3(1.5238)^2 + 4(1.1429)^2
    $$

    $$
    = 3(2.3220) + 4(1.3061) = 6.9660 + 5.2245 = 12.1905
    $$

    집단내 제곱합:

    $$
    \text{SS}_W = (2-\tfrac{4}{3})^2 + (0-\tfrac{4}{3})^2 + (2-\tfrac{4}{3})^2 + (6-4)^2 + (2-4)^2 + (2-4)^2 + (6-4)^2
    $$

    $$
    = 0.4444 + 1.7778 + 0.4444 + 4 + 4 + 4 + 4 = 18.6667
    $$

    $$
    W = \frac{12.1905 / 1}{18.6667 / 5} = \frac{12.1905}{3.7333} = 3.2653
    $$

    ```python
    import numpy as np
    from scipy.stats import levene, f

    x1 = np.array([2, 4, 6.])
    x2 = np.array([1, 5, 9, 13.])
    print(levene(x1, x2, center='median'))
    print(f"F critical (1, 5) at alpha=0.05: {f.ppf(0.95, 1, 5):.4f}")
    ```

    출력:

    ```text
    LeveneResult(statistic=3.2653061224489797, pvalue=0.13057297707695592)
    F critical (1, 5) at alpha=0.05: 6.6079
    ```

    $F(1, 5)$의 $\alpha = 0.05$ 임계값이 $6.61$이므로 $3.27 < 6.61$이 되어 $H_0$을 기각하지 못한다($p = 0.131$).

    표본분산이 $4$ 대 $26.67$로 6.7배나 차이 나는데도 그렇다. $n_1 = 3$, $n_2 = 4$라는 극단적으로 작은 표본에서는 어떤 검정도 무력하다. $\square$

**연습문제 4.** <span class="diff med" title="중간"></span> Brown-Forsythe 검정이 위치 이동에 불변임을 증명하라. 곧 집단 $i$의 모든 관측값에 상수 $c_i$를 더해도 검정통계량 $W$가 변하지 않음을 보여라.

</div>

??? success "풀이"

    집단 $i$의 모든 $j$에 대해 $x_{ij}' = x_{ij} + c_i$라 하자. 집단중앙값도 같은 양만큼 이동한다. $\tilde{x}_i' = \tilde{x}_i + c_i$. 변환값은

    $$
    z_{ij}' = |x_{ij}' - \tilde{x}_i'| = |(x_{ij} + c_i) - (\tilde{x}_i + c_i)| = |x_{ij} - \tilde{x}_i| = z_{ij}
    $$

    모든 $z_{ij}$ 값이 변하지 않으므로 검정통계량 $W$도 동일하다. 이는 Brown-Forsythe 검정이 집단평균이 아니라 각 집단 내부의 산포에만 의존함을 확인해 준다.

    **왜 이것이 중요한 성질인가.** 분산 검정이 위치에 의존한다면, 집단평균이 크게 다른 자료에서 분산 차이와 평균 차이를 구별할 수 없게 된다. 본문 보기에서 세 집단의 평균이 $12.6$, $21.5$, $32.6$으로 크게 다른데도 $W$가 오직 산포만 반영한다.

    **척도에는 불변이 아니다.** 모든 집단에 같은 상수 $c$를 **곱하면** 모든 $z_{ij}$가 $c$배가 되지만, $W$는 분자와 분모 모두 $c^2$배가 되므로 여전히 불변이다. 그러나 집단마다 **다른** 상수를 곱하면 분산비가 바뀌므로 $W$가 달라진다. 이는 당연하며, 그것이 바로 이 검정이 탐지하려는 것이다. $\square$

**연습문제 5.** <span class="diff med" title="중간"></span> Brown-Forsythe 검정은 중심화에 중앙값을 쓴다. 대안으로 **절사평균**(예: 10% 절사)을 쓸 수 있다. $z_{ij} = |x_{ij} - \bar{x}_{i,\text{trim}}|$을 계산하고 $z$ 값에 일원분산분석 $F$ 검정을 수행하는 판을 구현하라. $t(3)$ 분포 자료에서 중앙값 기반 판과 거짓 양성률을 비교하라.

</div>

??? success "풀이"

    ```python
    import numpy as np
    from scipy.stats import levene, trim_mean, f_oneway

    rng = np.random.default_rng(0)
    rej_med, rej_trim = 0, 0
    n_sims = 3000

    for _ in range(n_sims):
        g1 = rng.standard_t(3, 30)
        g2 = rng.standard_t(3, 30)
        g3 = rng.standard_t(3, 30)

        # 중앙값 중심 — Brown-Forsythe
        _, p_med = levene(g1, g2, g3, center='median')
        if p_med < 0.05:
            rej_med += 1

        # 절사평균 중심. 편차는 잘라 내지 않은 전체 표본에서 잰다
        # from the trimmed mean (data are NOT discarded)
        z_groups = [np.abs(g - trim_mean(g, 0.1)) for g in (g1, g2, g3)]
        _, p_trim = f_oneway(*z_groups)
        if p_trim < 0.05:
            rej_trim += 1

    print(f"Median centering FPR:       {rej_med/n_sims:.4f}")
    print(f"Trimmed mean centering FPR: {rej_trim/n_sims:.4f}")
    ```

    출력:

    ```text
    Median centering FPR:       0.0383
    Trimmed mean centering FPR: 0.0447
    ```

    $t(3)$ 분포에서 두 방법 모두 거짓 양성률을 0.05 근처로 조절한다. 절사평균 판이 $0.045$로 명목값에 조금 더 가깝다.

    대칭이면서 꼬리가 중간 정도인 자료에서는 절사평균이 중앙값보다 효율적인 위치 추정량이므로 대립가설 아래 검정력이 조금 높을 수 있다. 다만 극단적인 치우침에는 중앙값이 더 로버스트하다.

    !!! danger "이 구현과 SciPy의 `center='trimmed'`는 다르다"
        위 코드는 절사평균을 **중심으로만** 쓰고 편차는 **모든 관측값**에 대해 계산한다. 자료를 버리지 않는다.

        반면 **SciPy의 `stats.levene(..., center='trimmed')`는 자료 자체를 잘라낸다.** 각 집단에서 양 끝 10%를 제거한 뒤 남은 관측값으로만 검정을 수행한다. 15.5절 [Brown-Forsythe 검정](./brown_forsythe.md)에서 측정했듯 그 결과 **정규 자료에서도 크기가 0.12~0.19까지 부풀려진다**.

        | 방법 | 자료 처리 | 정규 자료 크기 |
        |---|---|---|
        | `center='median'` | 전부 사용 | 0.04 |
        | 위 코드(절사평균 중심) | 전부 사용 | 0.05 |
        | `center='trimmed'` | 양 끝 10% 제거 | **0.15** |

        가장 큰 편차들을 제거하면 F 통계량의 분모(집단내 제곱합)가 과도하게 줄어드는데, $F$ 기준분포가 이 선택 효과를 보정하지 않기 때문이다.

        절사평균 중심화를 쓰고 싶다면 위 코드처럼 **직접 구현**해야 한다. $\square$

**연습문제 6.** <span class="diff med" title="중간"></span> 3절은 이상점 하나가 "오염된 편차 여덟 개"를 만든다고 했다. 그 전파를 부등식으로 못 박자.

**(1)** 임의의 표본 $x_{i1}, \ldots, x_{in_i}$ 에 대해

$$
\frac{1}{n_i}\sum_j \lvert x_{ij} - \bar x_i\rvert \;\ge\; \frac{1}{n_i}\sum_j \lvert x_{ij} - \tilde x_i\rvert,
\qquad\text{곧}\qquad
\bar z_i^{(\text{평균})} \ge \bar z_i^{(\text{중앙값})}
$$

가 **언제나** 성립함을 보이고 등호 조건을 적으시오. 보기 1 의 $g_1$ 이 그 조건의 어디에 해당하는가?

**(2)** 3절에서 $g_1$ 의 값 하나를 $10 \to 34$ 로 바꾼 오염 자료에 대해 두 중심의 $\bar z_1$ 을 손으로 구하시오. $\bar z_2$ 와 $\bar z_3$ 은 두 중심에서 같음도 확인하시오.

**(3)** (2)의 세 $\bar z_i$ 로 집단간 제곱합을 두 중심에서 계산해 비를 구하시오. 3절이 보고한 $p = 0.1593$ 대 $0.5276$ 의 갈림이 그 비만으로는 설명되지 않는 까닭을 말하시오.

</div>

??? success "풀이"

    **(1) 중앙값이 절대편차의 합을 최소화한다.** $g(c) = \sum_j \lvert x_{ij} - c\rvert$ 는 볼록·조각선형이고, 자료점이 아닌 $c$ 에서

    $$
    g'(c) = \#\{j : x_{ij} < c\} - \#\{j : x_{ij} > c\}
    $$

    이다. 왼쪽 끝에서는 $-n_i$ 로 음수이고 $c$ 가 자료점을 하나씩 지날 때마다 $2$ 씩 커지므로, 아래쪽 점이 절반에 이르는 순간 기울기가 음에서 양으로 바뀐다. 그 전환점이 중앙값이다. $n_i = 2m-1$ 이 홀수면 최소점이 $x_{(m)}$ 한 점, $n_i = 2m$ 이 짝수면 **구간** $[x_{(m)}, x_{(m+1)}]$ 전체다. 그러므로 어떤 $c$ 를 넣어도 $g(c) \ge g(\tilde x_i)$ 이고, 특히 $c = \bar x_i$ 에서 주장한 부등식을 얻는다. 양변을 $n_i$ 로 나누면 편차평균의 부등식이다.

    **등호 조건은 "평균이 최소점 집합에 든다"는 것뿐이다.** 곧 홀수일 때는 $\bar x_i = x_{(m)}$ 이어야 하고, 짝수일 때는 $x_{(m)} \le \bar x_i \le x_{(m+1)}$ 이면 된다. 보기 1 의 $g_1$ 은 짝수 쪽 등호다. 평균 $12.625$ 가 최소화 구간 $[12, 13]$ 안에 들어 $g$ 가 두 중심에서 똑같이 $11$ 이었고, 그것이 보기 1(2)에서 분자가 보존된 까닭이었다. **$g_2$ 는 더 강한 등호다.** 평균과 중앙값이 둘 다 $21.5$ 라 중심 자체가 같다.

    **(2) 오염 자료에서는 부등식이 진짜 부등식이 된다.** 오염된 첫 집단을 $g_1^{\dagger} = (12, 15, 14, 34, 13, 14, 12, 11)$ 이라 쓰자. 정렬하면

    $$
    11,\; 12,\; 12,\; 13,\; 14,\; 14,\; 15,\; 34
    $$

    이고 합이 $125$ 이므로 중앙값은 $(13+14)/2 = 13.5$, 평균은 $125/8 = 15.625$ 다. 평균이 최소화 구간 $[13, 14]$ **밖**이므로 (1)의 등호 조건이 깨진다. 두 합을 재면

    $$
    \sum_j \lvert x_{1j}^{\dagger} - 13.5\rvert = 1.5+1.5+0.5+20.5+0.5+0.5+1.5+2.5 = 29,
    $$

    $$
    \sum_j \lvert x_{1j}^{\dagger} - 15.625\rvert = 3.625+0.625+1.625+18.375+2.625+1.625+3.625+4.625 = 36.75
    $$

    이다. 여덟 항을 더하지 않고 기울기로도 확인된다. $g$ 는 $[13,14]$ 에서 $29$ 로 평평하고, $(14,15)$ 에서는 아래쪽 여섯 개·위쪽 두 개이므로 기울기가 $4$, $(15,34)$ 에서는 아래쪽 일곱 개·위쪽 하나이므로 기울기가 $6$ 이다. 따라서 $g(15) = 29 + 4 \cdot 1 = 33$, $g(15.625) = 33 + 6 \cdot 0.625 = 36.75$. 그러므로

    $$
    \bar z_1^{(\text{중앙값})} = \frac{29}{8} = 3.625, \qquad \bar z_1^{(\text{평균})} = \frac{36.75}{8} = 4.59375
    $$

    로 평균 중심이 $0.96875$ 만큼 크다. **나머지 두 집단은 꼼짝하지 않는다.** $g_2$ 는 평균 = 중앙값 = $21.5$ 라 $\bar z_2 = 2$ 가 두 중심에서 같고, $g_3$ 은 오염되지 않은 $g_1$ 의 평행이동이므로 중심이 $32.5$ 든 $32.625$ 든 합이 $11$ 로 같아 $\bar z_3 = 1.375$ 가 같다.

    **(3) 분자는 2.16 배가 된다.** 전체 편차평균이 중앙값 쪽은 $(3.625+2+1.375)/3 = 7/3 = 2.333333$, 평균 쪽은 $(4.59375+2+1.375)/3 = 2.65625$ 이므로

    $$
    \mathrm{SS}_{\text{between}}^{(\text{중앙값})} = 8\left[\left(\tfrac{31}{24}\right)^2 + \left(\tfrac{1}{3}\right)^2 + \left(\tfrac{23}{24}\right)^2\right] = 21.58333,
    $$

    $$
    \mathrm{SS}_{\text{between}}^{(\text{평균})} = 8\left[(1.9375)^2 + (0.65625)^2 + (1.28125)^2\right] = 46.60938
    $$

    이고 비는 $46.60938/21.58333 = 2.159$ 다. 그런데 두 $W$ 의 비는 그보다 크다. 실제로 $W_{\text{중앙값}} = 0.659273$, $W_{\text{평균}} = 2.007338$ 로 비가 $3.045$ 다.

    **모자란 $1.41$ 배는 분모에서 온다.** 집단내 제곱합이 중앙값 쪽 $343.75$, 평균 쪽 $243.80$ 로 **중앙값 쪽이 더 크고**, 그 비 $343.75/243.80 = 1.410$ 을 곱하면 $2.159 \times 1.410 = 3.045$ 로 정확히 맞는다. 차이는 거의 전부 집단 1 에서 나온다($328.875$ 대 $229.055$). 중앙값 중심에서 이상점 자신의 편차가 $20.5$ 인데 그 집단의 편차평균이 $3.625$ 뿐이라 $(20.5-3.625)^2 = 284.8$ 이라는 거대한 항이 **분모로** 들어가는 것이다.

    **이것이 3절의 "이상점의 영향을 그 한 점에 가두어"를 수로 옮긴 모습이다.** 평균 중심은 오염을 분자로 보내 신호처럼 보이게 하고, 중앙값 중심은 오염을 분모로 보내 잡음처럼 보이게 한다. 분산 검정에서 이상점은 신호가 아니라 잡음으로 처리되는 쪽이 안전하다.

**연습문제 7.** <span class="diff med" title="중간"></span> 보기 1(2)에서 두 중심의 분자가 정확히 같았던 것은 $g_1$ 의 평균 $12.625$ 가 최소화 구간 $[12, 13]$ 안에 들었기 때문이다. 그 우연을 깨뜨려 보자. $g_1$ 의 값 $10$ 을 $4$ 로 바꾸어 $g_1^{\ast} = (12, 15, 14, 4, 13, 14, 12, 11)$ 로 두고, $g_2$ 는 그대로, $g_3^{\ast} = g_1^{\ast} + 20$ 으로 둔다.

**(1)** $g_1^{\ast}$ 의 중앙값과 평균을 구해 평균이 최소화 구간 밖임을 보이고, 조각선형성만으로 $g(\bar x_1^{\ast}) - g(\tilde x_1^{\ast})$ 를 **여덟 항을 더하지 않고** 구하시오.

**(2)** 보기 1(1)의 닫힌 꼴 $W = 56(a-b)^2/(2S_1+S_2)$ 가 이 자료에도 그대로 쓰이는 까닭을 밝히고, 두 중심에서 **분자**를 계산해 비를 적으시오. 보기 1(2)의 "두 $W$ 의 비는 분모만의 비"라는 규칙은 어떻게 되는가?

??? success "풀이"

    **(1) 평균이 구간을 벗어난다.** $g_1^{\ast}$ 을 정렬하면 $4, 11, 12, 12, 13, 14, 14, 15$ 이고 합이 $95$ 이므로 중앙값은 $x_{(4)}$ 와 $x_{(5)}$ 의 평균 $(12+13)/2 = 12.5$, 평균은 $95/8 = 11.875$ 다. 최소화 구간은 보기 1 과 똑같이 $[x_{(4)}, x_{(5)}] = [12, 13]$ 인데 $11.875 < 12$ 이므로 평균이 그 **밖**이다.

    기울기로 차이를 읽는다. $g$ 는 $[12, 13]$ 에서 평평하고 그 값은

    g(12.5) = 8.5+1.5+0.5+0.5+0.5+1.5+1.5+2.5 = 17
    $$

    **(2) 닫힌 꼴은 그대로 유효하다.** 보기 1(1)의 유도에 들어간 것은 $g_3$ 가 $g_1$ 의 평행이동이라는 사실과 $n_i = 8$, $k = 3$, $N = 24$ 라는 크기뿐이고 $g_1$ 의 구체적인 값은 쓰이지 않았다. $g_3^{\ast} = g_1^{\ast} + 20$ 이므로 $z_{3j}^{\ast} = z_{1j}^{\ast}$ 가 다시 성립하고 $W = 56(a-b)^2/(2S_1+S_2)$ 를 쓸 수 있다.

    56(2.1875-2)^2 = 56 \times 0.03515625 = 1.96875

    W_{\text{평균}} = \frac{1.96875}{99.1875} = 0.019849

**연습문제 8.** <span class="diff hard" title="어려움"></span> 연습문제 3 에서 Bartlett 의 거짓 양성률이 $n = 20$ 의 $0.675$ 에서 $n = 30$ 의 $0.730$ 으로 **커졌다.** 보통의 근사 오차라면 $n$ 이 커질 때 줄어들어야 한다. 그 역행을 수로 설명하자. Box(1953)에 따르면 4차 적률이 유한한 모집단에서 Bartlett 통계량 $M$ 은

$$
M \;\xrightarrow{d}\; \left(1 + \frac{\gamma_2}{2}\right)\chi^2_{k-1}, \qquad \gamma_2 = \beta_2 - 3
$$

을 따른다($\gamma_2 = 0$ 이면 정규 이론의 $\chi^2_{k-1}$ 로 돌아온다).

**(1)** $X = e^Z$, $Z \sim N(0,1)$ 의 적률 $E[X^m] = e^{m^2/2}$ 에서 출발해 $\beta_2 = e^4 + 2e^3 + 3e^2 - 3$ 임을 보이고 값을 구하시오. 연습문제 3 이 적은 초과첨도 $110.9$ 와 맞는가?

**(2)** 5장 [S²의 표준오차](../../ch05/applications/se_s2.md) 정리 1 로 $n = 30$ 에서 $\operatorname{Var}(S^2)/\sigma^4$ 를 구해 같은 $n$ 의 정규 이론값과 비를 적으시오.

**(3)** $k = 3$, $\alpha = 0.05$ 에서 Bartlett 의 **극한** 거짓 양성률을 계산하시오. $P(\chi^2_2 > x) = e^{-x/2}$ 와 $\chi^2_{0.95, 2} = 5.9915$ 를 쓰라. 그 값이 $0.675 \to 0.730$ 의 행렬을 어떻게 설명하는가?

**(4)** 브라운–포사이드는 왜 같은 운명을 피하는가? 이 쪽의 $W$ 가 무엇의 표집분포에 기대고 있는지로 답하시오.

</div>

??? success "풀이"

    **(1) 적률 네 개로 끝난다.** $E[X^m] = e^{m^2/2}$ 이므로 $\mu = E[X] = e^{1/2}$, $E[X^2] = e^2$, $E[X^3] = e^{9/2}$, $E[X^4] = e^8$ 이고

    $$
    \sigma^2 = e^2 - e = e(e-1) = 4.670774, \qquad \sigma^4 = e^2(e-1)^2 = 21.816132
    $$

    이다. 중심적률을 원적률로 펼치면

    $$
    \mu_4 = E[X^4] - 4\mu E[X^3] + 6\mu^2 E[X^2] - 3\mu^4
    = e^8 - 4e^{1/2}e^{9/2} + 6e \cdot e^2 - 3e^2
    = e^8 - 4e^5 + 6e^3 - 3e^2
    $$

    이다. 수로는 $2980.958 - 593.653 + 120.513 - 22.167 = 2485.651$ 이다. 이제 나누기만 남았는데, $\mu_4 = e^2(e^6 - 4e^3 + 6e - 3)$ 이고 $\sigma^4 = e^2(e-1)^2$ 이므로 $e^2$ 이 지워지고

    $$
    (e^2 - 2e + 1)(e^4 + 2e^3 + 3e^2 - 3) = e^6 - 4e^3 + 6e - 3
    $$

    을 곱셈으로 확인하면 ($e^5$ 항과 $e^4$ 항과 $e^2$ 항이 모두 지워진다)

    $$
    \beta_2 = e^4 + 2e^3 + 3e^2 - 3 = 54.5982 + 40.1711 + 22.1672 - 3 = 113.9364
    $$

    를 얻는다. 초과첨도는 $\gamma_2 = \beta_2 - 3 = 110.9364$ 로 연습문제 3 의 $110.9$ 와 맞는다. 2장의 하한 $\beta_2 \ge 1 + \gamma_1^2$ 과 견주면 이 분포의 치우침 $\gamma_1 = 6.185$ 가 요구하는 최소 첨도는 $39.3$ 인데, 실제 첨도는 그보다도 세 배 가까이 크다.

    **(2) $S^2$ 자체가 쉰 배 더 흔들린다.** 5장 정리 1 로

    $$
    \frac{\operatorname{Var}(S^2)}{\sigma^4} = \frac{1}{n}\left(\beta_2 - \frac{n-3}{n-1}\right)
    = \frac{1}{30}\left(113.9364 - \frac{27}{29}\right) = \frac{113.0054}{30} = 3.76685
    $$

    이고, 같은 $n$ 의 정규 이론값은 $2/(n-1) = 2/29 = 0.068966$ 이다. 비가 $54.62$, 표준오차로는 $\sqrt{54.62} = 7.39$ 배다. Bartlett 은 이 $S^2$ 들을 정규 이론의 눈금으로 읽으므로 분산의 차이를 과대평가할 수밖에 없다.

    **(3) 극한값이 $0.948$ 이다.** 척도인자가

    $$
    c = 1 + \frac{\gamma_2}{2} = 1 + 55.4682 = 56.4682
    $$

    이므로 극한에서 $M \approx c\,\chi^2_2$ 이고

    $$
    P(M > 5.9915) \to P\!\left(\chi^2_2 > \frac{5.9915}{56.4682}\right) = P(\chi^2_2 > 0.106103) = e^{-0.053052} = 0.9483
    $$

    이다. **Bartlett 의 기준분포가 표본이 커져도 옳아지지 않는다.** 눈금이 $56$ 배 어긋나 있고 그 어긋남은 $n$ 과 무관한 상수다. 그러므로 $0.675 \to 0.730$ 은 오차가 커지는 것이 아니라 유한표본 기각률이 **망가진 극한값 $0.948$ 을 향해 올라가는** 모습이다. 대수정규에서는 $S^2$ 의 분포 자체가 극단적으로 치우쳐 수렴이 느리므로 $n = 30$ 에서 아직 $0.730$ 에 머물러 있을 뿐이다. 15.3절의 "표본을 키우면 나빠진다"가 이 식의 한 줄 요약이다.

    **(4) $W$ 는 평균의 표집분포에만 기댄다.** 카이제곱 검정과 $F$ 검정과 Bartlett 은 $(n-1)S^2/\sigma^2 \sim \chi^2_{n-1}$ 을 쓰는데(5장 표본분산 정리 2), 이 분포는 정규성에서만 나오고 분산비는 그것을 분자와 분모에 **두 번** 쓴다(5장 분산비 정리 1). 반면 브라운–포사이드의 $W$ 는 $z_{ij} = \lvert x_{ij} - \tilde x_i\rvert$ 의 **집단평균들을 비교하는** 일원분산분석 $F$ 다. 평균의 표집분포는 중심극한정리가 지켜 주므로 $z$ 의 분포 모양이 어떻든 $n$ 이 커질수록 $F$ 근사가 좋아진다. 곧 정규성 의존이 "분포 전체의 모양"에서 "평균의 근사정규성"으로 내려앉는다.

    대가가 없지는 않다. $z$ 의 분포는 한쪽으로 치우쳐 있어 소표본에서 $F$ 근사가 약간 보수적이고, 연습문제 3 의 $0.031$ 이 그 자취다. 그러나 이 오차는 $n$ 과 함께 **줄어드는** 오차이고, Bartlett 의 $0.948$ 은 $n$ 과 함께 **다가가는** 재앙이다.

**연습문제 9.** <span class="diff hard" title="어려움"></span> 보기 1 은 중앙값 중심이 치르는 검정력의 대가가 "$p$ 값 소수 셋째 자리만큼"이라고 했지만 그것은 한 표본에서의 이야기였다. 그 맞바꿈을 모의실험으로 재자. $k = 3$, $n = 20$, 명목 $\alpha = 0.05$, 반복 20,000 회로 네 자리에서 평균 중심과 중앙값 중심의 기각률을 구하라.

| 자료 | 척도 | 재는 것 |
|---|---|---|
| 정규 | $(1, 1, 1)$ | 크기 |
| 정규 | $(1, 1, 2)$ | 검정력 |
| 대수정규 | $(1, 1, 1)$ | 크기 |
| 대수정규 | $(1, 1, 2)$ | 기각률 |

`scipy.stats.levene` 을 20,000 번 부르면 느리므로 $W$ 를 **벡터화해 직접** 계산하고, 한 표본에서 scipy 와 같은 $p$ 값을 주는지 먼저 확인하라. 정규성 아래 잃는 검정력과 치우침 아래 막는 거짓 양성을 수로 비교하고, 넷째 줄을 검정력 비교로 읽으면 안 되는 까닭을 밝히시오.

</div>

??? success "풀이"

    ```python
    import numpy as np
    from scipy.stats import f, levene


    def levene_p(groups, center):
        """groups: (k, B, n) 배열. 모의실험 B 회분의 p 값을 한꺼번에 돌려준다."""
        c = (np.median(groups, axis=2, keepdims=True) if center == "median"
             else groups.mean(axis=2, keepdims=True))
        z = np.abs(groups - c)                        # (k, B, n)  절대편차
        k, B, n = z.shape
        zbar = z.mean(axis=2)                         # (k, B)  집단별 편차평균
        ztot = z.mean(axis=(0, 2))                    # (B,)    전체 편차평균
        ssb = n * ((zbar - ztot) ** 2).sum(axis=0)
        ssw = ((z - zbar[:, :, None]) ** 2).sum(axis=(0, 2))
        N = k * n
        W = (ssb / (k - 1)) / (ssw / (N - k))
        return f.sf(W, k - 1, N - k)


    rng = np.random.default_rng(2024)
    n, B = 20, 20000

    # 벡터화한 구현이 scipy 와 같은 값을 주는지 한 표본에서 먼저 확인한다.
    chk = rng.normal(0, 1, (3, 1, n))
    for c in ("median", "mean"):
        print(f"{c:>6}: 벡터화 p = {levene_p(chk, c)[0]:.8f}, "
              f"scipy p = {levene(*[g[0] for g in chk], center=c)[1]:.8f}")

    specs = [("N  (1,1,1)", "normal", (1, 1, 1)),
             ("N  (1,1,2)", "normal", (1, 1, 2)),
             ("LN (1,1,1)", "lognorm", (1, 1, 1)),
             ("LN (1,1,2)", "lognorm", (1, 1, 2))]
    print("\n        자료  평균 중심  중앙값 중심     차이")
    for name, kind, scales in specs:
        if kind == "normal":
            G = np.stack([rng.normal(0, s, (B, n)) for s in scales])
        else:
            G = np.stack([s * rng.lognormal(0, 1, (B, n)) for s in scales])
        r_mean = (levene_p(G, "mean") < 0.05).mean()
        r_med = (levene_p(G, "median") < 0.05).mean()
        print(f"{name:>12}{r_mean:>11.4f}{r_med:>13.4f}{r_mean - r_med:>9.4f}")
    ```

    출력:

    ```text

      mean: 벡터화 p = 0.17895690, scipy p = 0.17895690

            자료  평균 중심  중앙값 중심     차이
      N  (1,1,1)     0.0570       0.0386   0.0184
      N  (1,1,2)     0.8197       0.7698   0.0500
      LN (1,1,1)     0.2576       0.0391   0.2185
      LN (1,1,2)     0.5558       0.2437   0.3122
    ```

    **구현이 맞다.** 손으로 조립한 $W$ 의 $p$ 값이 `levene` 과 소수 여덟째 자리까지 같다. 한 번 부르는 비용은 같은데 20,000 회를 통째로 돌리므로 네 자리를 모두 재는 데 1 초가 걸리지 않는다.

    **정규성 아래 대가는 검정력 $0.0500$ 이다.** $\sigma = (1,1,2)$ 에서 평균 중심 $0.8197$, 중앙값 중심 $0.7698$ 이다. 상대적으로는 $6.1\%$ 손실이다. 다만 공짜 비교가 아니다. 등분산 정규에서 두 검정의 크기가 $0.0570$ 대 $0.0386$ 으로 평균 중심이 명목값을 조금 넘고 중앙값 중심은 그 아래이므로, 검정력 차이의 일부는 **더 무른 문턱**에서 온 것이다(15.5절 표의 $n = 25$ 줄 $0.057$ 대 $0.036$ 과 같은 그림이다).

    **치우침 아래 이득은 거짓 양성 $0.2185$ 다.** 등분산 대수정규에서 평균 중심은 $0.2576$ 으로 명목값의 **다섯 배**를 기각하는데 중앙값 중심은 $0.0391$ 로 통제된다. 맞바꿈을 한 줄로 적으면 이렇다. **가장 유리한 조건에서 검정력 $0.05$ 를 내주고, 조건이 나빠지면 거짓 양성 $0.22$ 를 막는다.** 분산 검정을 쓰는 상황에서 자료가 정규라는 보장이 없다면 이 거래는 명백히 유리하다.

    **넷째 줄은 검정력 비교가 아니다.** 척도가 $(1,1,2)$ 인 대수정규에서 평균 중심의 $0.5558$ 에는 셋째 줄에서 본 크기 $0.2576$ 이 이미 섞여 있다. 크기가 다른 두 검정의 기각률을 나란히 놓고 "평균 중심이 더 셈" 이라고 말할 수 없다. 검정력을 겨루려면 먼저 두 검정의 크기를 같게 맞춰야 하며, 그렇게 맞추고 나면 평균 중심의 이점은 사라진다. 셋째 줄이 넷째 줄의 해석을 막는 셈이다.

**연습문제 10.** <span class="diff hard" title="어려움"></span> 등분산을 먼저 검정해 보고 그 결과에 따라 합동분산 $t$ 검정과 Welch $t$ 검정 중 하나를 고르는 관행이 널리 쓰인다. 이 쪽의 브라운–포사이드를 그 사전검정으로 쓰면 두 단계 절차가 명목 수준을 지키는가?

$n_1 = 10$, $n_2 = 30$, 두 집단 모두 참 평균이 0 인 정규, $\sigma_1/\sigma_2 \in \{1, 2, 4\}$ 에서 평균이 같다는 영가설에 대한 세 절차의 **크기**를 반복 20,000 회로 재라.

- **(가)** 늘 합동분산 $t$ 검정
- **(나)** 늘 Welch $t$ 검정
- **(다)** 브라운–포사이드의 $p \ge 0.05$ 면 합동분산 $t$, 아니면 Welch

세 통계량을 모두 벡터화해 구현하고 한 표본에서 scipy 와 맞춰 보라. 두 단계 절차가 가장 나쁜 자리는 $\sigma_1/\sigma_2$ 가 얼마일 때이며 왜 그런가? 사전검정의 기각률을 함께 출력해 답의 근거로 쓰라.

    ```python
    import numpy as np
    from scipy.stats import f, t as tdist, levene, ttest_ind


    def bf_p(x1, x2):
        """두 집단 Brown-Forsythe 검정의 p 값. x 는 (B, n) 배열."""
        z1 = np.abs(x1 - np.median(x1, axis=1, keepdims=True))
        z2 = np.abs(x2 - np.median(x2, axis=1, keepdims=True))
        n1, n2 = z1.shape[1], z2.shape[1]
        N = n1 + n2
        m1, m2 = z1.mean(axis=1), z2.mean(axis=1)
        g = (n1 * m1 + n2 * m2) / N
        ssb = n1 * (m1 - g) ** 2 + n2 * (m2 - g) ** 2
        ssw = ((z1 - m1[:, None]) ** 2).sum(axis=1) + ((z2 - m2[:, None]) ** 2).sum(axis=1)
        return f.sf(ssb / (ssw / (N - 2)), 1, N - 2)


    def t_p(x1, x2, welch):
        """두 표본 t 검정의 양쪽 p 값. welch=False 면 합동분산 판."""
        n1, n2 = x1.shape[1], x2.shape[1]
        d = x1.mean(axis=1) - x2.mean(axis=1)
        v1, v2 = x1.var(axis=1, ddof=1), x2.var(axis=1, ddof=1)
        if welch:
            se2 = v1 / n1 + v2 / n2
            df = se2 ** 2 / ((v1 / n1) ** 2 / (n1 - 1) + (v2 / n2) ** 2 / (n2 - 1))
        else:
            sp2 = ((n1 - 1) * v1 + (n2 - 1) * v2) / (n1 + n2 - 2)
            se2 = sp2 * (1 / n1 + 1 / n2)
            df = np.full_like(d, n1 + n2 - 2)
        return 2 * tdist.sf(np.abs(d) / np.sqrt(se2), df)


    rng = np.random.default_rng(7)
    n1, n2, B = 10, 30, 20000

    # 세 구현을 한 표본에서 scipy 와 맞춰 본다.
    a, b = rng.normal(0, 2, (1, n1)), rng.normal(0, 1, (1, n2))
    print(f"BF     : {bf_p(a, b)[0]:.6f} vs scipy {levene(a[0], b[0], center='median')[1]:.6f}")
    print(f"합동 t : {t_p(a, b, False)[0]:.6f} vs scipy {ttest_ind(a[0], b[0]).pvalue:.6f}")
    print(f"Welch t: {t_p(a, b, True)[0]:.6f} vs scipy "
          f"{ttest_ind(a[0], b[0], equal_var=False).pvalue:.6f}")

    print("\n sd1/sd2    합동 t    Welch    두 단계   사전검정 기각률")
    for s1 in (1.0, 2.0, 4.0):
        x1 = rng.normal(0, s1, (B, n1))      # 작은 집단에 큰 분산을 준다
        x2 = rng.normal(0, 1.0, (B, n2))     # 두 집단의 참 평균은 모두 0
        p_pre = bf_p(x1, x2)
        p_pool, p_welch = t_p(x1, x2, False), t_p(x1, x2, True)
        p_two = np.where(p_pre >= 0.05, p_pool, p_welch)   # 사전검정으로 고른 판
        print(f"{s1:>8.0f}{(p_pool < 0.05).mean():>10.4f}{(p_welch < 0.05).mean():>9.4f}"
              f"{(p_two < 0.05).mean():>11.4f}{(p_pre < 0.05).mean():>15.4f}")
    ```

    **Welch 는 세 자리에서 모두 명목값을 지킨다.** $0.0518$, $0.0531$, $0.0517$ 이다. 합동분산 $t$ 는 분산비가 커질수록 무너져 $0.0498 \to 0.1530 \to 0.2374$ 가 된다. 작은 집단에 큰 분산을 주었으므로 합동분산이 참 표준오차를 과소평가하는 쪽이다.

    **가장 나쁜 자리는 $\sigma_1/\sigma_2 = 2$ 다.** 두 단계 절차의 크기가 $0.0901$ 로 명목값의 **1.8 배**다. 양 끝에서는 오히려 괜찮다. $\sigma_1/\sigma_2 = 1$ 에서는 어느 쪽을 골라도 타당하므로 $0.0520$ 이고, $= 4$ 에서는 사전검정이 $98.4\%$ 기각해 거의 늘 Welch 로 가므로 $0.0546$ 이다.

    **까닭은 마지막 열에 있다.** 사전검정 기각률이 $0.0412 \to 0.5978 \to 0.9839$ 다. $\sigma_1/\sigma_2 = 2$ 는 **사전검정이 동전 던지기에 가까운** 자리다. $n_1 = 10$ 이라는 작은 표본에서 분산비 4 배를 $60\%$ 밖에 못 잡으므로, 등분산이 실제로 깨진 자료의 $40\%$ 가 "등분산을 기각하지 못했다"는 이유로 합동분산 $t$ 로 흘러간다. 그 $40\%$ 가 $0.1530$ 짜리 검정을 받으니 전체 크기가

    $$
    0.40 \times 0.153 + 0.60 \times 0.053 \approx 0.093
    $$

    쯤으로 올라간다. 관측값 $0.0901$ 과 맞는다(사전검정과 $t$ 검정이 **같은 자료**를 쓰므로 독립이 아니어서 정확히 맞지는 않는다).

    **결론은 사전검정을 빼는 것이다.** 사전검정의 제2종 오류가 그대로 본검정의 제1종 오류로 바뀌고, 두 단계의 오류율이 합쳐지는데 명목 수준은 한 단계 몫만 계산되어 있다. 더구나 등분산이 참일 때 Welch 를 쓰는 비용이 $0.0518$ 대 $0.0498$, 사실상 없다. 5장 [X̄₁ - X̄₂의 표집분포 (이분산과 불균형)](../../ch05/applications/diff_means_welch.md) 정리 1 과 11장 Welch 분산분석이 내린 결론이 여기서 수로 확인된다. **분산을 검정하는 것은 분산 자체가 관심사일 때 할 일이고, 평균 비교의 전처리로 할 일이 아니다.**

## 정리하며

브라운–포사이드의 **호출 방법**은 간단하다.

- **`levene(..., center='median')` 이 곧 이 검정이다.** 별도 함수가 없으며, 기본값이므로 인자를 생략해도 같다.
- **이름과 구현이 어긋나 보이는 점**을 기억해 두면 문서를 읽을 때 혼동이 줄어든다.
- **중앙값 계산이 집단별로 이루어진다.** 전체 중앙값이 아니라 각 집단의 중앙값에서 편차를 잰다.
- **표본이 짝수면 중앙값이 두 값의 평균**이라 절대편차에 0 이 포함되지 않을 수 있다. 소표본에서 미세한 차이를 만든다.
- **보고할 때 어느 중심을 썼는지 밝힌다.** 평균 중심과 중앙값 중심이 다른 답을 줄 수 있기 때문이다.
