# 연습문제

**연습문제 1. 두 분산 비교를 위한 F 검정**

두 생산라인이 비슷한 제품을 만드는데, 제품 무게의 변동성이 두 라인 사이에 다르다고 의심된다. 표본자료(그램)는 다음과 같다.

- **생산라인 1:** $[14.2, 13.8, 15.1, 14.7, 14.5, 14.6, 15.0, 14.8]$
- **생산라인 2:** $[15.2, 14.8, 15.6, 15.0, 14.9, 15.3, 15.5, 14.9]$

유의수준 5%에서 F 검정으로 두 라인의 분산이 유의하게 다른지 판단하라.

??? success "연습문제 1 풀이"
    **가설**

    - 귀무가설 $H_0$: 분산이 같다. 즉 $\sigma_1^2 = \sigma_2^2$.
    - 대립가설 $H_1$: 분산이 다르다. 즉 $\sigma_1^2 \neq \sigma_2^2$.

    **검정통계량**은 두 표본분산의 비이다.

    $$
    F = \frac{s_1^2}{s_2^2}
    $$

    ```python
    import numpy as np
    from scipy.stats import f

    line1 = np.array([14.2, 13.8, 15.1, 14.7, 14.5, 14.6, 15.0, 14.8])
    line2 = np.array([15.2, 14.8, 15.6, 15.0, 14.9, 15.3, 15.5, 14.9])

    var1, var2 = line1.var(ddof=1), line2.var(ddof=1)
    F_stat = var1 / var2
    df1, df2 = len(line1) - 1, len(line2) - 1

    alpha = 0.05
    lower = f.ppf(alpha / 2, df1, df2)
    upper = f.ppf(1 - alpha / 2, df1, df2)
    p = 2 * min(f.cdf(F_stat, df1, df2), f.sf(F_stat, df1, df2))
    ```

    **결과**

    | 양 | 값 |
    |:---|---:|
    | $s_1^2$ | 0.18125 |
    | $s_2^2$ | 0.08857 |
    | $F$ | **2.046** |
    | 임계값 (하한, 상한) | $(0.200,\ 4.995)$ |
    | $p$값 | 0.366 |

    $F = 2.046$이 임계구간 $(0.200,\ 4.995)$ 안에 있으므로 귀무가설을 기각하지 못한다. 두 생산라인의 분산이 유의하게 다르다는 증거가 없다.

    **표본분산의 비가 2배가 넘는데도 유의하지 않다는 점에 주목하라.** 각 라인의 표본이 8개뿐이라 $F$ 분포의 임계구간이 $0.2$부터 $5.0$까지로 매우 넓다. 분산을 비교하려면 평균을 비교할 때보다 훨씬 많은 자료가 필요하다.

**연습문제 2. 등분산성에 대한 Levene 검정**

세 가지 교수법을 세 학생 집단에 적용했다. 학기가 끝난 뒤 점수는 다음과 같았다.

- **집단 1:** $[78, 82, 85, 90, 87]$
- **집단 2:** $[65, 70, 72, 68, 74]$
- **집단 3:** $[92, 88, 94, 89, 91]$

Levene 검정으로 세 집단의 점수 분산이 같은지 판단하라.

??? success "연습문제 2 풀이"
    **가설**

    - 귀무가설 $H_0$: 세 집단의 분산이 같다.
    - 대립가설 $H_1$: 적어도 한 집단의 분산이 다르다.

    Levene 검정은 각 집단 중앙값으로부터의 절대편차를 계산한 뒤, 그 편차의 평균이 집단 간에 다른지 검정한다.

    ```python
    from scipy.stats import levene, bartlett

    group1 = [78, 82, 85, 90, 87]
    group2 = [65, 70, 72, 68, 74]
    group3 = [92, 88, 94, 89, 91]

    print(levene(group1, group2, group3))
    print(bartlett(group1, group2, group3))
    ```

    **결과**

    | 집단 | 표본분산 |
    |:---|---:|
    | 집단 1 | 21.30 |
    | 집단 2 | 12.20 |
    | 집단 3 | 5.70 |

    | 검정 | 통계량 | $p$값 |
    |:---|---:|---:|
    | Levene | 0.750 | 0.493 |
    | Bartlett | 1.475 | 0.478 |

    $p = 0.493 > 0.05$이므로 귀무가설을 기각하지 못한다. 세 집단의 분산이 다르다는 증거가 없다.

    표본분산이 $21.3$과 $5.7$로 거의 4배 차이 나는데도 유의하지 않다. 집단당 관측이 5개뿐이기 때문이다. **분산의 동질성 검정은 검정력이 매우 낮다**는 점을 기억해야 한다. 기각하지 못했다는 것이 등분산의 증거는 아니다.

**연습문제 3. Bartlett 검정과 Levene 검정의 결과가 엇갈릴 때**

정규분포를 따르지 않는 두 자료에 대해 Bartlett 검정을 수행하여 낮은 $p$값을 얻었다(등분산이라는 $H_0$ 기각). 그런데 Levene 검정에서는 높은 $p$값이 나왔다(기각 실패). 두 결과를 어떻게 해석해야 하는가?

??? success "연습문제 3 풀이"
    - 정규성 가정이 깨진 상황에서 Bartlett 검정의 결과는 **신뢰할 수 없다.** Bartlett 검정은 비정규성에 매우 민감하며, 귀무가설 기각이 실제 분산 차이가 아니라 분포의 모양 때문일 수 있다.
    - Levene 검정은 정규성 위반에 **덜 민감하므로** 이 상황에서 더 믿을 만한 결과를 준다. 두 자료의 분산이 같다고 결론짓는 것이 합리적이다.

    17장의 [순열검정 개요](../../ch17/permutation/permutation.md) 연습문제 3에서 이 현상을 수치로 확인했다. $t(3)$ 자료에서 $F$ 검정의 제1종 오류율이 $0.318$까지 올라가는 반면 Levene 검정은 $0.038$을 유지한다.

**연습문제 4. 분산 비교와 평균 비교 결과의 해석**

두 모집단에서 표본을 뽑아 분석했다. Levene 검정 결과 높은 $p$값이 나왔고(등분산이라는 $H_0$ 기각 실패), 등분산을 가정한 $t$ 검정에서는 $p$값이 0.001보다 작았다. 두 결과를 어떻게 해석해야 하는가?

??? success "연습문제 4 풀이"
    - Levene 검정은 두 모집단의 **분산이 같다**는 가정을 뒷받침한다.
    - $t$ 검정 결과는 두 모집단의 **평균이 유의하게 다르다**는 강한 증거를 제공한다.
    - 두 결과는 모순이 아니다. **분산이 같으면서 평균이 크게 다른 두 모집단은 얼마든지 존재한다.** Levene 검정이 $t$ 검정에 쓰인 등분산 가정을 정당화해 주므로, 관측된 평균 차이가 진짜라는 결론이 오히려 강화된다.

    분산은 분포의 **퍼짐**을, 평균은 **위치**를 나타낸다. 두 정규분포가 같은 폭을 가지면서 서로 멀리 떨어져 있는 그림을 떠올리면 된다.
