# 연습문제: 정칙화 기법

## 개념

**연습문제 1.** 능형회귀 추정량 $\hat{\boldsymbol{\beta}}_{\text{ridge}} = (\mathbf{X}^\top\mathbf{X} + \lambda\mathbf{I})^{-1}\mathbf{X}^\top\mathbf{y}$를 생각하자.

**(a)** $\lambda \to 0$일 때 $\hat{\boldsymbol{\beta}}_{\text{ridge}} \to \hat{\boldsymbol{\beta}}_{\text{OLS}}$임을 보여라.

**(b)** $\lambda \to \infty$일 때 $\hat{\boldsymbol{\beta}}_{\text{ridge}} \to \mathbf{0}$임을 보여라.

**(c)** $\mathbf{X}^\top\mathbf{X}$가 특이행렬이더라도 모든 $\lambda > 0$에 대해 $\mathbf{X}^\top\mathbf{X} + \lambda\mathbf{I}$가 양정치임을 증명하라.

**연습문제 2.** 직교 설계($\mathbf{X}^\top\mathbf{X} = n\mathbf{I}$)에서 능형회귀와 라쏘의 닫힌 형태 해를 유도하라. 라쏘는 정확히 0을 만들지만 능형회귀는 그렇지 않은 이유를 기하적으로 설명하라.

**연습문제 3.** 엘라스틱넷의 **그룹 효과**를 설명하라. 예측변수들이 강하게 상관되어 있을 때 라쏘가 실패하는 이유는 무엇인가? $X_1 = X_2 + \varepsilon$($\varepsilon$은 작다)인 예를 들어 라쏘, 능형회귀, 엘라스틱넷이 각각 어떻게 행동할지 서술하라.

**연습문제 4.** 능형회귀의 유효자유도는 $\text{df}(\lambda) = \sum_{j=1}^p \frac{d_j^2}{d_j^2 + \lambda}$이며 $d_j$는 $\mathbf{X}$의 특이값이다.

**(a)** $\text{df}(0) = p$이고 $\text{df}(\infty) = 0$임을 보여라.

**(b)** $\text{df}(\lambda)$는 $\lambda$에 대해 단조감소하는가?

**(c)** 라쏘에 대응하는 양은 어떻게 정의하겠는가?

## 계산

**연습문제 5.** 모형 $y = 3x_1 - 2x_2 + 0.5x_3 + \varepsilon$($\varepsilon \sim N(0,1)$)에서 관측 $n = 100$개를 생성하고, 잡음 예측변수 17개($x_4, \ldots, x_{20}$)를 함께 만들어라.

**(a)** OLS, 능형회귀, 라쏘, 엘라스틱넷을 적합하고 계수 추정값을 비교하라.

**(b)** 어느 방법이 참 예측변수 3개를 올바르게 식별하는가?

**(c)** 5-겹 교차검증으로 각 방법의 최적 $\lambda$를 고르고 검정 MSE를 보고하라.

**연습문제 6.** 예측변수가 상관된 그룹으로 묶인 자료를 만들어라. $X_1, X_2, X_3$은 강하게 상관되어 있고($\rho = 0.95$) 모두 0이 아닌 효과를 갖는다. $X_4, X_5, X_6$은 또 다른 상관 그룹으로 역시 0이 아닌 효과를 갖는다. 나머지 14개는 잡음이다.

**(a)** 라쏘를 적합하라. 그룹마다 하나씩 고르는가, 여러 개를 고르는가?

**(b)** $\alpha = 0.5$인 엘라스틱넷을 적합하고 선택된 변수를 비교하라.

**(c)** 두 방법의 계수 경로를 그려라.

**연습문제 7.** 능형회귀를 sklearn 없이 **직접 구현**하라.

**(a)** $\mathbf{X}, \mathbf{y}, \lambda$를 받아 닫힌 형태 공식으로 $\hat{\boldsymbol{\beta}}_{\text{ridge}}$를 반환하는 함수를 작성하라.

**(b)** 사영행렬 지름길을 이용해 하나 남기기 교차검증을 구현하라.

**(c)** 구현 결과가 `sklearn.linear_model.Ridge`와 일치하는지 확인하라.

**연습문제 8.** 라쏘의 좌표하강 알고리즘을 구현하라.

**(a)** 연성 문턱 연산자 $S_\lambda(z)$를 작성하라.

**(b)** 수렴 판정을 포함한 전체 좌표하강 반복을 구현하라.

**(c)** 해 경로를 `sklearn.linear_model.Lasso`와 비교하라.
