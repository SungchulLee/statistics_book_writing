# 정규성을 얻기 위한 변수변환

자료가 정규성에서 크게 벗어나면 정규성 가정에 기대는 통계 방법이 더 이상 적절하지 않을 수 있다. 흔한 대응 가운데 하나는 변환을 적용해 자료를 더 정규에 가깝게 만드는 것이다.

---

## 1. 흔한 변환

널리 쓰이는 변환은 다음과 같다.

**로그 변환**: 오른쪽으로 치우친 자료에 적합하다.

$$
X' = \log(X)
$$

**제곱근 변환**: 역시 오른쪽으로 치우친 자료에 쓰며, 특히 작은 값이 있을 때 유용하다.

$$
X' = \sqrt{X}
$$

**Box-Cox 변환**: 최적의 거듭제곱 모수 $\lambda$를 찾아 자료를 변환하는 더 유연한 변환이다.

$$
X' = \frac{X^\lambda - 1}{\lambda}, \quad \lambda \neq 0
$$

<div class="exbox" markdown>

**보기 1.** <span class="diff easy" title="쉬움"></span> 로그 변환과 Box-Cox 변환. 척도 $2$인 지수분포에서 $n = 1000$개를 뽑아 $\log(X+1)$과 $\text{Box-Cox}(X+1)$을 나란히 그린다.

**(1)** 지수분포의 왜도가 **척도와 무관하게 정확히 2**임을 보이시오. 이동 없이 $\log X$를 쓰면 왜도가 얼마가 되는지 닫힌 꼴로 구하시오.

**(2)** 코드는 로그와 Box-Cox 둘 다에 `+1`을 더한다. 이 이동 상수가 답을 얼마나 흔드는지 수로 보이시오.

**(3)** Box-Cox가 왜도를 $0.07$까지 떨어뜨렸다. 이 자료는 이제 정규라고 말할 수 있는가.

</div>

??? success "풀이"

    **(1) 해석적으로.** 왜도는 위치와 척도에 불변이므로 $X = sE$($E \sim \text{Exp}(1)$)라 쓰면 척도 $s$가 떨어져 나간다. $\text{Exp}(1)$의 적률은 $\mathbb{E}[E^k] = k!$이므로

    $$
    \mathbb{E}[E] = 1, \qquad \operatorname{Var}(E) = 2! - 1^2 = 1
    $$

    이고 3차 중심적률은

    $$
    \mathbb{E}[(E-1)^3] = \mathbb{E}[E^3] - 3\,\mathbb{E}[E]\,\mathbb{E}[E^2] + 2(\mathbb{E}[E])^3
    = 6 - 3 \times 1 \times 2 + 2 = 2
    $$

    이다. 따라서

    $$
    \gamma_1 = \frac{2}{1^{3/2}} = 2
    $$

    로 **정확히 2**이며, $s$가 들어오지 않는다.

    이동 없이 로그를 씌우면 어떻게 되는가. $\log X = \log s + \log E$이고 더해진 상수는 왜도를 바꾸지 않으므로 $\log E$만 보면 된다. 그 분포를 알아내기 위해 누적분포함수를 계산한다.

    $$
    P(-\log E \le t) = P(E \ge e^{-t}) = e^{-e^{-t}}
    $$

    오른쪽이 **표준 검벨분포**의 누적분포함수다. 곧 $-\log E$가 표준 검벨을 따르므로 $\log E$는 그것을 뒤집은 분포이고, 왜도의 부호도 뒤집힌다. 표준 검벨의 왜도가 $12\sqrt{6}\,\zeta(3)/\pi^3$이므로

    $$
    \gamma_1(\log X) = -\frac{12\sqrt{6}\,\zeta(3)}{\pi^3} = -1.1395
    $$

    이다. **이동 없는 로그는 과교정이다.** 왜도를 $+2$에서 0 으로 끌어내리는 것이 아니라 $-1.14$까지 밀어 보낸다. 절댓값이 절반 가까이 줄기는 하지만 부호가 뒤집힌다.

    **(2)–(3) 수치적으로.** 먼저 쪽의 코드를 그대로 돌린다.

    ```python
    import numpy as np
    import matplotlib.pyplot as plt
    from scipy.stats import boxcox

    np.random.seed(0)

    # 오른쪽으로 치우친 자료
    skewed_data = np.random.exponential(scale=2, size=1000)

    # 로그 변환. 1 을 더하는 것은 0 에 가까운 값에서 로그가 발산하는 것을
    # 막기 위해서다. 이 자료는 양수이지만 0 에 아주 가까운 값이 섞여 있다.
    log_transformed_data = np.log(skewed_data + 1)

    # Box-Cox 는 로그를 포함하는 변환들의 한 묶음이고, 그중 자료를 가장
    # 정규에 가깝게 만드는 lambda 를 스스로 고른다. lambda=0 이 곧 로그다.
    boxcox_transformed_data, best_lambda = boxcox(skewed_data + 1)

    # 셋을 나란히 놓고 어느 쪽이 더 대칭에 가까운지 본다.
    fig, axs = plt.subplots(1, 3, figsize=(15, 4))
    axs[0].hist(skewed_data, bins=30)
    axs[0].set_title('Original Data')

    axs[1].hist(log_transformed_data, bins=30)
    axs[1].set_title('Log Transformed Data')

    axs[2].hist(boxcox_transformed_data, bins=30)
    axs[2].set_title(f'Box-Cox Transformed Data (λ={best_lambda:.2f})')

    plt.show()
    ```

    ![원자료와 두 변환의 히스토그램](./img/transformations_29.png)

    그림은 치우침이 줄어드는 것을 보여 주지만 왜도도 첨도도 눈으로는 읽히지 않는다. 수로 재어야 한다.

    ```python
    import numpy as np
    from scipy import stats
    from scipy.optimize import brentq
    from scipy.special import zeta
    from scipy.stats import boxcox

    np.random.seed(0)
    x = np.random.exponential(scale=2, size=1000)
    n = len(x)

    print(f"이론 왜도(지수) = 2  (척도와 무관)")
    print(f"이론 왜도(log X) = -12 sqrt(6) zeta(3) / pi^3 = "
          f"{-12 * np.sqrt(6) * zeta(3) / np.pi ** 3:.4f}")

    # 쪽의 표는 scipy 기본값 bias=True, 곧 g1 이다. G1 도 함께 찍는다.
    y = np.log(x + 1)
    b, lam = boxcox(x + 1)
    print(f"Box-Cox lambda_hat = {lam:.4f}")
    print("                g1        G1      g2(초과)   shapiro p")
    for name, v in [("원자료", x), ("log(X+1)", y), ("BoxCox", b), ("log(X)", np.log(x))]:
        print(f"  {name:9s} {stats.skew(v):+8.4f}  {stats.skew(v, bias=False):+8.4f}  "
              f"{stats.kurtosis(v):+8.4f}   {stats.shapiro(v)[1]:.3g}")

    # 이동 상수 c 가 답을 얼마나 흔드는가.
    print("  이동 c    G1(log(X+c))")
    for c in [0.0, 0.25, 0.5, 1.0, 5.0, 20.0]:
        t = np.log(x + c) if c > 0 else np.log(x)
        print(f"  {c:6.2f}    {stats.skew(t, bias=False):+8.4f}")
    c0 = brentq(lambda c: stats.skew(np.log(x + c), bias=False), 0.01, 1.0)
    print(f"표본왜도를 0 으로 만드는 c = {c0:.4f}")

    SE = np.sqrt(6 * n * (n - 1) / ((n - 2) * (n + 1) * (n + 3)))
    print(f"정규 아래 SE(G1) = {SE:.4f}")
    print(f"  log(X+1): G1/SE = {stats.skew(y, bias=False) / SE:.3f}")
    print(f"  BoxCox  : G1/SE = {stats.skew(b, bias=False) / SE:.3f}")
    ```

    **(1)의 확인.** 원자료의 표본왜도는 $g_1 = 2.0526$으로 이론값 $2$를 잘 맞힌다. 이동 없는 $\log X$는 $G_1 = -1.0182$가 나왔는데 이론값은 $-1.1395$다. 차이 $0.12$가 커 보이지만, $n = 1000$에서 이 분포의 $G_1$은 표준편차가 $0.18$쯤이고 작은 표본에서 크기가 줄어드는 쪽으로 편향되므로 어긋남이 아니다. $n$을 $10^7$으로 키우면 $-1.1357$이 되어 이론값에 붙는다.

    !!! warning "어느 판본의 왜도인가"

        쪽의 표에 적힌 $2.0526$, $0.4914$, $0.0747$은 `scipy.stats.skew`의 **기본값 `bias=True`**가 주는 $g_1$이다. 보정판 $G_1$은 $2.0557$, $0.4921$, $0.0748$으로 셋째 자리에서 갈린다. 아래에서 $\mathrm{SE}$와 견줄 때는 그 $\mathrm{SE}$ 식이 **$G_1$의 것**이므로 $G_1$을 쓴다.

    **(2) 이동 상수가 답을 지배한다.** `+1` 은 코드 주석이 말하듯 0 에 가까운 값을 막으려는 장치이지만, 실제로는 **결과를 정하는 모수**로 작동한다.

    | $c$ | $G_1(\log(X+c))$ |
    |---|---|
    | $0$ | $-1.0182$ |
    | $0.25$ | $-0.0049$ |
    | $0.5$ | $+0.2328$ |
    | $1$ | $+0.4921$ |
    | $5$ | $+1.1357$ |
    | $20$ | $+1.6261$ |

    $c$를 $0$에서 $20$으로 옮기는 동안 왜도가 $-1.02$에서 $+1.63$까지 **연속으로 쓸고 지나간다.** $c$가 커지면 $\log(X+c) \approx \log c + X/c$로 거의 선형이 되어 원자료의 왜도 $2$로 돌아가므로 당연한 일이다. 곧 $c$는 "교정을 얼마나 할지"를 정하는 손잡이다.

    이 표본에서 왜도를 정확히 0 으로 만드는 값은 $c = 0.2538$이고, 코드가 고른 $c = 1$은 거기서 네 배 멀다. 그래서 $\log(X+1)$의 왜도 $0.4921$은 **$c$를 1 로 고른 결과**이지 로그변환의 성능이 아니다. 더 나쁜 것은 이 손잡이가 보고되지 않는다는 점이다. "로그변환을 했다"는 문장만 읽으면 $c$가 몇이었는지 알 수 없고, 다른 $c$로는 숫자가 재현되지 않는다. **이동 상수를 쓰면 반드시 그 값을 밝혀야 한다.**

    **(3) 아니다. 왜도가 0 에 가까워졌을 뿐 정규는 아니다.**

    왜도만 보면 Box-Cox가 훌륭하다. $2.05$에서 $0.075$로 27배 줄었고, $G_1/\mathrm{SE} = 0.967$이니 대칭성 자체는 나무랄 데가 없다($\log(X+1)$은 $6.363$으로 압도적으로 기각된다). 그런데 샤피로–윌크는

    $$
    p = 3.33 \times 10^{-11}
    $$

    으로 **정규성을 단호히 기각한다.** 원자료의 $4.86\times10^{-33}$보다는 나아졌지만 기각은 기각이다.

    까닭은 **첨도**다. 초과첨도 $g_2$를 보면 원자료 $+6.48$이 Box-Cox 뒤에 $-0.92$가 되었다. 부호를 건너 반대쪽으로 지나쳐 버린 것이고, 절댓값 $0.92$는 $n = 1000$에서 쉽게 잡히는 크기다. Box-Cox는 거듭제곱 하나로 꼬리를 누르는데, 지수분포의 오른쪽 꼬리를 정규만큼 눌러 놓으면 **왼쪽이 0 에서 잘려 평평해진다.** 변환된 자료는 종 모양이 아니라 어깨가 넓은 모양이다.

    더 근본적으로, **지수분포를 정규로 보내는 거듭제곱변환은 존재하지 않는다.** 로그정규는 로그 하나로 정확히 정규가 되지만(이 절의 「변환 시연」 쪽 보기 1) 지수분포에는 그런 짝이 없다. Box-Cox는 주어진 계열 안에서 **가장 덜 나쁜** $\lambda$를 고르는 것뿐이고, 가장 덜 나쁜 것이 좋다는 보장은 없다.

    그러므로 "이런 변환은 자료를 모수적 검정에 적합하게 해 준다"는 결론은 이 자료에서는 **성립하지 않는다.** 교훈은 **왜도 하나로 변환의 성공을 판정하지 말라**는 것이다. 왜도·첨도·정규성 검정을 함께 보아야 하고, 셋이 갈리면 그 자료는 변환으로 구제되지 않는 자료다. 이어지는 두 쪽의 붓스트랩과 비모수 방법이 그런 자료를 위해 있다.

## 연습문제

<div class="drillbox" markdown>

**연습문제 1.** <span class="diff med" title="중간"></span>
변수 $Y$가 모두 양수이고 오른쪽으로 치우친 분포를 갖는다. 로그 변환 $Y' = \log(Y)$를 적용하고 이것이 왜 치우침을 줄이는 경우가 많은지 설명하라.

</div>

??? success "풀이"
    로그함수는 오목하다. 큰 값을 작은 값보다 더 많이 압축한다. 오른쪽으로 치우친 자료에서는 긴 오른쪽 꼬리(큰 값)가 크게 압축되고 왼쪽(0 근처의 작은 값)은 늘어난다. 이것이 오른쪽 꼬리를 중심 쪽으로 끌어당겨 비대칭을 줄인다.

    형식적으로 $Y$가 대수정규분포를 따르면($\log Y \sim N(\mu, \sigma^2)$) 로그 변환이 완벽하게 정규인 자료를 만든다. 근사적으로 대수정규인 자료(소득, 주가, 생물학적 측정값에서 흔하다)에서도 로그 변환이 정규성을 크게 개선한다.

    주의: 로그 변환은 $Y \leq 0$에서 정의되지 않는다. 0이 있는 자료에는 작은 상수 $c$를 써서 $\log(Y + c)$를 쓴다.

<div class="drillbox" markdown>

**연습문제 2.** <span class="diff med" title="중간"></span>
Box-Cox 변환족은 $\lambda \neq 0$일 때 $Y^{(\lambda)} = (Y^\lambda - 1)/\lambda$, $\lambda = 0$일 때 $\log(Y)$이다. $\lambda = 1$, $\lambda = 0.5$, $\lambda = -1$은 각각 어떤 변환에 해당하는가?

</div>

??? success "풀이"

    - $\lambda = 1$: $Y^{(1)} = (Y - 1)/1 = Y - 1$ (선형 이동, 사실상 변환 없음).
    - $\lambda = 0.5$: $Y^{(0.5)} = (\sqrt{Y} - 1)/0.5 = 2(\sqrt{Y} - 1)$ (선형 재척도화를 제외하면 제곱근 변환).
    - $\lambda = 0$: $Y^{(0)} = \log(Y)$ (로그 변환).
    - $\lambda = -1$: $Y^{(-1)} = (1/Y - 1)/(-1) = 1 - 1/Y$ (선형 재척도화를 제외하면 역수 변환).

    최적 $\lambda$는 최대가능도로 고른다. 변환된 자료가 가장 정규에 가까워지는 $\lambda$를 찾는 것이다. Python에서는 보통 `scipy.stats.boxcox`로 수행한다.

<div class="drillbox" markdown>

**연습문제 3.** <span class="diff med" title="중간"></span>
오른쪽으로 치우친 자료에 로그 변환을 적용하면 회귀계수의 해석이 달라진다. 모형 $\log(Y) = \beta_0 + \beta_1 X + \varepsilon$에서 $\hat{\beta}_1$을 어떻게 해석하는지 설명하라.

</div>

??? success "풀이"
    로그-선형 모형에서 지수를 취하면 $Y = e^{\beta_0 + \beta_1 X + \varepsilon}$이다. $X$가 한 단위 늘면 $Y$의 기댓값에 $e^{\beta_1}$이 곱해진다.

    $$
    \frac{E[Y \mid X+1]}{E[Y \mid X]} \approx e^{\beta_1} \approx 1 + \beta_1 \quad (\beta_1\text{이 작을 때})
    $$

    따라서 $\beta_1$은 $X$가 한 단위 변할 때 $Y$의 비례적(백분율) 변화에 가깝다. 예를 들어 $\beta_1 = 0.05$이면 $X$가 1 늘 때 $Y$가 약 5% 늘어남과 연관된다.

    이 곱셈적 해석은 소득, 가격, 생물학적 성장 같은 여러 응용에서 자연스럽다.

<div class="drillbox" markdown>

**연습문제 4.** <span class="diff med" title="중간"></span>
정규성이 위배되어도 자료 변환이 권장되지 않는 상황을 두 가지 들어라.

</div>

??? success "풀이"

    1. **원래 척도가 과학적으로 의미 있을 때:** 연구 질문이 원래 단위의 차이에 관한 것이라면(예: "이 처치가 혈압을 최소 10 mmHg 낮추는가?") 자료를 변환하면 해석이 달라진다. 로그 척도의 10 차이는 10 mmHg가 아니다. 이럴 때는 원래 척도에서 타당한 방법(붓스트랩, 로버스트 방법)을 써야 한다.

    2. **변환이 해석을 어렵게 만들 때:** 0이 많은 변수(예: 의료비, 보험 청구)를 로그 변환하려면 임시방편적 조정($\log(Y+1)$)이 필요하고, 역변환한 추정값이 편향된다($\log Y$의 평균은 $Y$의 평균의 로그가 아니다). 이런 경우에는 일반화선형모형(감마 GLM, Tweedie 회귀)이 대개 더 낫다.

**연습문제 5.** <span class="diff med" title="중간"></span>
이 쪽의 Box-Cox 변환은 $X' = (X^\lambda - 1)/\lambda$ 이다. 왜 그냥 $X'' = X^\lambda$ 를 쓰지 않는지 따져 본다.

**(1)** $\lambda \to 0$ 에서 $(X^\lambda - 1)/\lambda \to \log X$ 임을 보이고, 이 성질이 연습문제 2 의 목록과 `boxcox` 가 하는 일에 왜 필요한지 말하시오.

**(2)** 보기 1 의 자료는 $\hat\lambda = -0.4127$ 을 골라 $G_1 = +0.0748$, $g_2 = -0.9237$, 샤피로–윌크 $p = 3.33 \times 10^{-11}$ 을 얻었다. 같은 $\hat\lambda$ 로 $X'' = (X+1)^{\hat\lambda}$ 를 썼다면 이 세 수가 각각 어떻게 되는가.

**(3)** $\lambda < 0$ 에서 두 꼴의 결정적인 차이를 하나 말하시오.

</div>

??? success "풀이"

    **(1)** $x^\lambda = e^{\lambda \log x} = 1 + \lambda \log x + \tfrac{\lambda^2}{2}(\log x)^2 + \cdots$ 이므로

    $$
    \frac{x^\lambda - 1}{\lambda} = \log x + \frac{\lambda}{2}(\log x)^2 + O(\lambda^2) \xrightarrow[\lambda \to 0]{} \log x
    $$

    이다. $\lambda = 0$ 을 로그로 **정의** 하면 족이 $\lambda$ 에 연속이 되고, 그래서 연습문제 2 의 $\lambda = 1$(변환 없음), $0.5$(제곱근), $0$(로그), $-1$(역수)이 끊김 없는 한 줄에 꿰인다. $X^\lambda$ 꼴로는 $\lambda \to 0$ 에서 $X^0 \equiv 1$ 이라 정보가 모두 사라져 로그가 족 안에 들어오지 못한다. `boxcox` 는 $\lambda$ 를 연속으로 훑으며 가능도를 최대화하는데, 그 가능도가 $\lambda = 0$ 에서 구멍이 나면 최적화가 성립하지 않는다.

    **(2)** 두 꼴은 아핀 관계 $X' = (X'' - 1)/\lambda$ 로 묶여 있고, $\hat\lambda = -0.4127 < 0$ 이므로 기울기 $1/\hat\lambda$ 가 **음수** 다. 곧 $X''$ 는 $X'$ 를 뒤집어 늘인 척도다.

    - 왜도는 3차(홀수) 중심적률을 쓰므로 부호가 뒤집힌다: $G_1 = -0.0748$.
    - 초과첨도는 4차(짝수)라 그대로다: $g_2 = -0.9237$.
    - 샤피로–윌크 $W = (\sum_i a_i x_{(i)})^2 / \sum_i (x_i - \bar{x})^2$ 는 위치·척도에 불변이고, 계수가 $a_{n+1-i} = -a_i$ 로 반대칭이어서 자료를 뒤집으면 순서와 부호가 함께 뒤집혀 분자가 그대로다. 그러므로 $p = 3.33 \times 10^{-11}$ 로 **똑같다.**

    정규성 판정에 관해서는 두 꼴이 같은 답을 준다. 달라지는 것은 왜도의 부호처럼 **방향** 을 가진 양이다.

    **(3)** $h_\lambda(x) = (x^\lambda - 1)/\lambda$ 는 $h_\lambda'(x) = x^{\lambda - 1} > 0$ 이라 **모든** $\lambda$ 에서 증가함수다. 반면 $x^\lambda$ 는 $\lambda < 0$ 에서 감소함수이므로 자료의 **순서가 뒤집힌다**: 가장 큰 관측값이 가장 작은 변환값이 되고, 분위수·중앙값·회귀계수의 부호가 모두 거꾸로 읽힌다. 「정리하며」가 역수변환에 "순서가 뒤집힌다" 고 적은 것, 연습문제 2 의 $\lambda = -1$ 이 $1/Y$ 가 아니라 $1 - 1/Y$ 인 것이 모두 이 때문이다. 곧 빼고 나누는 꼴은 멋이 아니라 **연속성과 순서 보존** 두 가지를 사는 값이다.

**연습문제 6.** <span class="diff med" title="중간"></span>
「정리하며」는 로그 척도의 평균을 되돌리면 평균이 아니라 **중앙값** 이 된다고 적었다. 보기 1 의 자료, 곧 척도 $s = 2$ 인 지수분포 $X = 2E$ 에서 이 말을 점검한다. 보기 1 의 $\mathbb{E}[E^k] = k!$ 은 $\mathbb{E}[E^t] = \Gamma(1+t)$ 로 넓혀 쓸 수 있고, $\Gamma'(1) = -\gamma$ 이다($\gamma = 0.5772$ 는 오일러–마스케로니 상수).

**(1)** $\exp(\mathbb{E}[\log X])$ 를 구하고 $\mathbb{E}[X]$ 와 견주시오.

**(2)** 그 값이 $X$ 의 중앙값과는 같은가. 같지 않다면 보기 1 의 풀이에 나온 수 가운데 어느 것이 그 까닭인가.

**(3)** (1) 에서 얻은 부등호의 방향이 지수분포라는 사실과 무관하게 늘 성립함을 보이시오.

</div>

??? success "풀이"

    **(1)** $\log X = \log 2 + \log E$ 이다. $\mathbb{E}[E^t] = \Gamma(1+t)$ 를 $t$ 로 미분하고 $t = 0$ 을 넣으면 $\mathbb{E}[E^t \log E]$ 가 $\mathbb{E}[\log E]$ 가 되므로

    $$
    \mathbb{E}[\log E] = \Gamma'(1) = -\gamma, \qquad \mathbb{E}[\log X] = \log 2 - \gamma = 0.6931 - 0.5772 = 0.1159
    $$

    이고, 되돌리면

    $$
    \exp(\mathbb{E}[\log X]) = 2e^{-\gamma} = 2 \times 0.5615 = 1.1229
    $$

    이다. $\mathbb{E}[X] = 2$ 이므로 되돌린 값은 평균의 $e^{-\gamma} = 56.1\%$, 곧 **43.9% 작다.** 이 양은 모집단의 기하평균이고, seed 0 의 같은 표본에서 재면 $1.1168$ 로 이론값에 붙는다.

    **(2)** 중앙값은 $s\log 2 = 2 \times 0.6931 = 1.3863$ 이므로 $1.1229$ 는 중앙값보다도 $19.0\%$ 작다. 까닭은 보기 1 풀이의

    $$
    \gamma_1(\log X) = -\frac{12\sqrt{6}\,\zeta(3)}{\pi^3} = -1.1395
    $$

    다. 단조변환은 중앙값을 보존하므로 $\operatorname{med}(X) = \exp(\operatorname{med}(\log X))$ 는 언제나 맞다. 그런데 우리가 되돌리는 것은 로그 척도의 **평균** 이고, 평균이 중앙값과 같으려면 로그 척도의 분포가 대칭이어야 한다. $\log X$ 는 왜도 $-1.1395$ 로 왼쪽으로 치우쳐 평균 $0.1159$ 가 중앙값 $\log(2\log 2) = 0.3266$ 보다 작고, 그 차이가 지수를 거쳐 $1.1229 < 1.3863$ 이 된다.

    곧 "역변환하면 중앙값" 은 **로그 척도가 정확히 정규일 때(로그정규)만** 참이다. 변환이 정규화에 실패한 이 자료에서 되돌린 값은 평균도 중앙값도 아니다.

    **(3)** 로그는 엄격히 오목하다(연습문제 1). 젠센 부등식으로 $\mathbb{E}[\log X] \le \log \mathbb{E}[X]$ 이고, 양변에 지수를 취하면

    $$
    \exp(\mathbb{E}[\log X]) \le \mathbb{E}[X]
    $$

    이다. $X$ 가 상수가 아니면 엄격한 부등호다. 기하평균 $\le$ 산술평균의 다른 얼굴이다. 해석: 로그 척도에서 평균을 내고 되돌리면 **반드시** 아래로 치우친 값이 나오므로, 알고 싶은 양이 원래 척도의 평균일 때는(연습문제 4 의 첫째 상황) 변환이 질문 자체를 바꾼다.

**연습문제 7.** <span class="diff hard" title="어려움"></span>
보기 1 의 풀이에서 이동 상수 $c$ 는 $G_1(\log(X+c))$ 를 $-1.0182$ 에서 $+1.6261$ 까지 연속으로 쓸고 지나갔고, 그 표본에서는 $c_0 = 0.2538$ 에서 정확히 0 을 지났다. 이 현상의 뼈대를 세 점만으로 드러낸다. 자료가 $0 < a < b < d$ 세 개뿐이라 하자.

**(1)** 세 점 표본의 표본왜도의 부호가 $\operatorname{sign}(a + d - 2b)$ 임을 보이시오.

**(2)** $\log(x+c)$ 의 표본왜도를 0 으로 만드는 $c$ 를 닫힌 꼴로 구하고, 그런 $c$ 가 많아도 하나임을 보이시오.

**(3)** 오른쪽으로 치우쳐 있는데도($a + d > 2b$) 그런 양수 $c$ 가 존재하지 않는 세 점을 하나 들고, 그 자료가 보기 1 의 자료와 무엇이 다른지 말하시오.

</div>

??? success "풀이"

    **(1)** 평균을 $m$, 편차를 $u = a - m$, $v = b - m$, $w = d - m$ 이라 하면 $u + v + w = 0$ 이다. 항등식

    $$
    u^3 + v^3 + w^3 - 3uvw = (u+v+w)(u^2+v^2+w^2-uv-vw-wu) = 0
    $$

    이므로 3차 중심적률 $\tfrac13(u^3+v^3+w^3) = uvw$ 의 부호가 곧 왜도의 부호다(분모 $s^3 > 0$). $u < 0$, $w > 0$ 이므로

    $$
    \operatorname{sign}(g_1) = \operatorname{sign}(uvw) = -\operatorname{sign}(v) = -\operatorname{sign}\!\left(b - \frac{a+b+d}{3}\right) = \operatorname{sign}(a+d-2b)
    $$

    이다. 세 점에서는 가운데 점이 양 끝의 **산술평균** 보다 왼쪽에 있으면 오른쪽 치우침이다.

    **(2)** (1) 을 변환된 세 점 $\log(a+c) < \log(b+c) < \log(d+c)$ 에 그대로 적용하면

    $$
    \operatorname{sign}(g_1) = \operatorname{sign}\!\left(\log\frac{(a+c)(d+c)}{(b+c)^2}\right) = \operatorname{sign}\big((a+c)(d+c) - (b+c)^2\big)
    $$

    이다. 괄호를 풀면 $c^2$ 이 지워진다.

    $$
    (a+c)(d+c) - (b+c)^2 = ad + (a+d)c - b^2 - 2bc = (a+d-2b)\,c - (b^2 - ad)
    $$

    $c$ 의 **일차함수** 다. 따라서 $a + d \neq 2b$ 이면 영점이 정확히 하나이고

    $$
    c = \frac{b^2 - ad}{a + d - 2b}
    $$

    이다. 일차함수라 부호가 한 번만 바뀌므로, 왜도가 $c$ 에 대해 한 방향으로만 단조롭게 움직인다는 것도 같이 나온다. 보기 1 의 표가 $c$ 를 키울 때 $-1.0182$ 에서 $+1.6261$ 로 쉬지 않고 올라간 것, 그리고 영점 $c_0 = 0.2538$ 이 하나뿐이었던 것이 이 구조다.

    **(3)** $\{a, b, d\} = \{1, 2, 10\}$ 을 보자. $a + d - 2b = 7 > 0$ 이라 오른쪽으로 치우쳐 있다. 그런데 $b^2 = 4 < ad = 10$ 이므로 공식은

    $$
    c = \frac{4 - 10}{7} = -0.857 < 0
    $$

    을 준다. 양수 해가 없다. 실제로 $c = 0$ 인 순수 로그에서도 $\log 1 + \log 10 - 2\log 2 = \log 2.5 > 0$ 이라 왜도가 여전히 양수($g_1 = +0.443$)이고, $c$ 를 키우면 원자료 쪽으로 더 커진다.

    차이는 가운데 점이 양 끝의 **기하평균** $\sqrt{ad}$ 의 어느 쪽에 있느냐다. $b < \sqrt{ad}$ 이면 로그조차 **미교정** 이라 양수 $c$ 로는 왜도를 0 까지 내릴 수 없다. 보기 1 의 지수 자료는 반대쪽이었다. 이동 없는 로그가 왜도를 $-1.0182$ 까지 **지나치게** 밀어 놓았기 때문에 $0$ 과 $\infty$ 사이에 영점 $c_0 = 0.2538$ 이 생겼다. 경계인 $b = \sqrt{ad}$, 곧 세 점이 등비수열이면 답이 $c = 0$ 이다. $\{1, 2, 4\}$ 의 로그 $0,\ 0.6931,\ 1.3863$ 은 등차가 되어 표본왜도가 정확히 0 이다.

    해석: $c$ 는 교정의 세기를 돌리는 손잡이지만 그 범위에 끝이 있다. $c \ge 0$ 으로는 "로그만큼" 보다 더 센 교정을 할 수 없으므로, 로그가 모자라는 자료는 이동 상수로 구제되지 않는다.

**연습문제 8.** <span class="diff hard" title="어려움"></span>
보기 1 의 풀이는 $n = 1000$ 에서

$$
\mathrm{SE}(G_1) = \sqrt{\frac{6n(n-1)}{(n-2)(n+1)(n+3)}} = 0.0773
$$

을 써서 $\log(X+1)$ 은 $G_1/\mathrm{SE} = 6.363$, Box-Cox 는 $0.967$ 을 얻었다. 왜도의 값은 그대로 두고 표본크기만 바꾼다. 유의수준 5%, 양쪽검정($\lvert z \rvert \ge 1.96$)으로 한다.

**(1)** $\log(X+1)$ 의 왜도 $G_1 = 0.4921$ 이 유의해지려면 $n$ 이 적어도 얼마여야 하는가. $\mathrm{SE}(G_1) \approx \sqrt{6/n}$ 으로 먼저 어림한 뒤 위의 정확한 식으로 확인하시오.

**(2)** Box-Cox 의 $G_1 = 0.0748$ 은 $n$ 이 얼마부터 유의해지는가.

**(3)** (1) 과 (2) 를 "이 변환은 성공했는가" 라는 물음에 대한 답으로 묶어 한 문단으로 쓰시오.

</div>

??? success "풀이"

    **(1)** 어림식으로

    $$
    \frac{\lvert G_1 \rvert}{\sqrt{6/n}} \ge 1.96 \iff n \ge 6\left(\frac{1.96}{G_1}\right)^2 = 6\left(\frac{1.96}{0.4921}\right)^2 = 95.2
    $$

    이다. 정확한 식으로 확인하면 $n = 92$ 에서 $\mathrm{SE} = 0.2513$, $z = 1.958$ 로 아슬아슬하게 못 넘고, $n = 93$ 에서 $\mathrm{SE} = 0.2500$, $z = 1.968$ 로 넘는다. 곧 **$n \ge 93$.** 거꾸로 읽으면 왜도가 $0.4921$ 인 자료라도 $n \le 92$ 면 "왜도가 0 과 다르다" 고 말할 수 없다.

    **(2)** 같은 계산을 $G_1 = 0.0748$ 로 한다. 어림식은 $n \ge 6(1.96/0.0748)^2 = 4119.6$ 을 주고, 정확한 식으로는 $n = 4116$ 에서 $z = 1.9598$, $n = 4117$ 에서 $z = 1.9601$ 이므로 **$n \ge 4117$.** $n$ 을 네 배 남짓 키우는 것만으로 $0.967$ 이 유의해진다.

    | 변환 | $G_1$ | $n = 1000$ 의 $z$ | 유의해지는 최소 $n$ |
    |---|---|---|---|
    | $\log(X+1)$ | $0.4921$ | $6.363$ | $93$ |
    | Box-Cox | $0.0748$ | $0.967$ | $4117$ |

    **(3)** 왜도의 **값** 은 표본크기와 무관한 자료의 성질인데, 왜도 검정의 **판정** 은 거의 전부 $n$ 이 정한다. $\mathrm{SE}$ 가 $\sqrt{6/n}$ 으로 줄기 때문에 같은 $G_1$ 이라도 $z$ 는 $\sqrt{n}$ 에 비례해 커진다. 그래서 $\log(X+1)$ 의 $0.4921$ 은 히스토그램에서 꼬리가 보일 만큼 심한 이탈인데도 $n \le 92$ 면 그대로 통과하고, Box-Cox 의 $0.0748$ 은 어떤 실용적 기준으로도 무해한 크기인데도 $n \ge 4117$ 이면 기각된다. 작은 표본은 변환의 실패를 못 잡고, 큰 표본은 변환의 성공마저 기각한다. 그러므로 "정규성 검정을 통과했다" 는 보고는 $n$ 을 밝히지 않으면 뜻이 없고, 판정은 $n$ 과 함께 자라는 $G_1/\mathrm{SE}$ 가 아니라 $G_1$ 자체의 크기 — 효과크기 — 로 내려야 한다. 보기 1 이 Box-Cox 를 두고 "왜도가 0 에 가까워졌을 뿐 정규는 아니다" 라고 한 결론도 이 눈으로 읽어야 한다. 그 자료가 샤피로–윌크에서 $p = 3.33 \times 10^{-11}$ 로 기각된 것은 남은 이탈이 실재한다는 사실과 $n = 1000$ 이라는 사실이 **함께** 만든 결과다.

**연습문제 9.** <span class="diff hard" title="어려움"></span>
보기 1 의 Box-Cox 결과는 $G_1 = 0.0748$, $g_2 = -0.9237$, 샤피로–윌크 $p = 3.33 \times 10^{-11}$ 이었다. 정규분포 아래 $n = 1000$ 에서 초과첨도의 표준오차를 $\mathrm{SE}(g_2) \approx \sqrt{24/n}$ 로 써도 된다.

**(1)** 왜도와 초과첨도 각각의 $z$ 값을 구하고, 두 적률만으로 정규성을 기각할 수 있는지 판정하시오.

**(2)** 두 $z$ 를 합친 $z_1^2 + z_2^2$ 이 자유도 2 의 카이제곱을 따른다고 보고 p 값을 구하시오. 샤피로–윌크의 $3.33 \times 10^{-11}$ 과 견주면 어느 쪽이 센가.

**(3)** 그 차이가 어디서 오는가. 보기 1 의 풀이가 변환된 자료의 **모양** 에 대해 한 말을 근거로 답하시오.

</div>

??? success "풀이"

    **(1)** $\mathrm{SE}(G_1) = 0.0773$ 이므로 $z_1 = 0.0748/0.0773 = 0.967$ 로 대칭성은 조금도 의심스럽지 않다. 첨도는

    $$
    \mathrm{SE}(g_2) = \sqrt{\frac{24}{1000}} = 0.1549, \qquad z_2 = \frac{-0.9237}{0.1549} = -5.962
    $$

    이고 양쪽 p 값이 $2.5 \times 10^{-9}$ 다. **초과첨도 하나만으로도 정규성은 기각된다.** 왜도를 보면 통과, 첨도를 보면 기각이니 두 수 가운데 하나만 골라 보고하면 결론이 뒤집힌다. 보기 1 이 왜도만으로 변환의 성공을 판정하지 말라고 한 까닭이 수로 드러난 자리다.

    **(2)** 두 $z$ 를 합치면

    $$
    z_1^2 + z_2^2 = 0.967^2 + 5.962^2 = 0.935 + 35.55 = 36.49
    $$

    이고, 자유도 2 의 카이제곱 생존함수가 $e^{-t/2}$ 라 손으로 계산된다.

    $$
    P(\chi^2_2 \ge 36.49) = e^{-18.25} = 1.2 \times 10^{-8}
    $$

    샤피로–윌크의 $3.33 \times 10^{-11}$ 은 이보다 약 $360$ 배 작다. **샤피로–윌크가 더 세다.**

    **(3)** 3차·4차 적률만 보는 검정은 그 두 수에 들어오지 않는 이탈을 보지 못한다. 보기 1 의 풀이는 Box-Cox 뒤의 자료가 "종 모양이 아니라 어깨가 넓은 모양" 이고, 그 까닭이 지수분포의 오른쪽 꼬리를 정규만큼 누르면 **왼쪽이 0 에서 잘려 평평해진다** 는 데 있다고 했다. 곧 남은 이탈의 정체는 왼쪽 끝이 절단된 모양, 다시 말해 분포 전체의 생김새다. 적률 둘은 이것을 "첨도가 음수" 라는 한 수로만 요약하지만, 샤피로–윌크는 정렬된 관측값 $x_{(1)} \le \cdots \le x_{(n)}$ 을 정규 순서통계량의 기대위치에 맞춰 보는 통계량이라 $\sum_i a_i x_{(i)}$ 에 **모든 분위수** 가 들어가고, 평평해진 왼쪽 끝을 그 자리에서 직접 본다.

    해석: 적률 검정은 미리 정해둔 두 방향으로만 보고, 적합도 검정은 분포 전체를 본다. 그래서 적률 검정이 통과시킨 자료가 정규라는 보장은 없다. 변환의 성공을 왜도 하나로 판정하는 것은 그 두 방향 가운데 하나만 보는 일이다.

**연습문제 10.** <span class="diff hard" title="어려움"></span>
보기 1 의 풀이는 "지수분포를 정규로 보내는 거듭제곱변환은 존재하지 않는다" 고 단언했다. 이것을 증명한다. $X$ 는 척도 $s$ 인 지수분포를 따르고, 변환은 $h_\lambda(x) = (x^\lambda - 1)/\lambda$ $(\lambda \neq 0)$, $h_0(x) = \log x$ 다.

**(1)** $\lambda > 0$ 과 $\lambda < 0$ 각각에서 $h_\lambda(X)$ 의 치역을 구하고, 그것만으로 $h_\lambda(X)$ 가 정규분포를 따를 수 없음을 보이시오.

**(2)** $\lambda = 0$ 인 경우를 처리해 증명을 완성하시오.

**(3)** (1) 의 논증은 지수분포의 어떤 성질을 썼는가. 그 성질을 공유하는 분포 전체에 대해 (1)–(2) 가 무엇을 말해 주는지, 그리고 「정리하며」의 박스–콕스 항목과 어떻게 맞물리는지 쓰시오.

</div>

??? success "풀이"

    **(1)** $X > 0$ 이고 $x \mapsto x^\lambda$ 는 $(0, \infty)$ 를 $(0, \infty)$ 로 보내는 전단사이므로 $X^\lambda$ 의 치역은 $(0, \infty)$ 다.

    - $\lambda > 0$ 이면 $1/\lambda > 0$ 이라 $h_\lambda(X) = (X^\lambda - 1)/\lambda > -1/\lambda$ 로 **아래로 유계** 다. 치역은 $(-1/\lambda, \infty)$.
    - $\lambda < 0$ 이면 $1/\lambda < 0$ 이라 부등호가 뒤집혀 $h_\lambda(X) < -1/\lambda = 1/\lvert \lambda \rvert$ 로 **위로 유계** 다. 치역은 $(-\infty, 1/\lvert \lambda \rvert)$.

    퇴화하지 않은 정규분포는 모든 실수에서 밀도가 양수이므로 임의의 $t$ 에 대해 $P(Z \le t) > 0$ 이고 $P(Z \ge t) > 0$ 이다. 그런데 $\lambda > 0$ 이면

    $$
    P\big(h_\lambda(X) \le -1/\lambda\big) = 0
    $$

    이고, $\lambda < 0$ 이면 $P(h_\lambda(X) \ge 1/\lvert \lambda \rvert) = 0$ 이다. 정규라면 두 확률이 모두 양수여야 하므로 모순이다. 따라서 $\lambda \neq 0$ 인 어떤 거듭제곱변환도 $X$ 를 정규로 만들지 못한다.

    **(2)** $\lambda = 0$ 에서는 $\log X$ 의 치역이 $\mathbb{R}$ 전체라 유계성 논증이 통하지 않는다. 대신 적률을 쓴다. 보기 1 의 풀이에서 $-\log E$ 가 표준 검벨분포를 따르므로

    $$
    \gamma_1(\log X) = -\frac{12\sqrt{6}\,\zeta(3)}{\pi^3} = -1.1395 \neq 0
    $$

    이다. 정규분포의 왜도는 0 이고 왜도는 위치·척도에 불변이므로, 척도 $s$ 가 무엇이든 $\log X$ 는 정규가 아니다. (1) 과 합치면 모든 $\lambda$ 에서 실패하므로 Box-Cox 족에는 지수분포를 정규로 보내는 원소가 없다. $\square$

    **(3)** (1) 이 쓴 것은 **지지집합이 한쪽으로 유계라는 사실** 하나, 곧 $X > 0$ 뿐이다. 지수분포의 다른 성질은 전혀 쓰지 않았다. 그러므로 (1) 은 양수 자료 전체로 그대로 번진다. **$\lambda \neq 0$ 인 Box-Cox 변환은 어떤 양수 분포도 정확히 정규로 만들지 못한다.** 남는 가능성은 $\lambda = 0$ 하나이고, $\log X$ 가 정규라는 것은 정의상 $X$ 가 로그정규라는 뜻이다. 결론은 **Box-Cox 족이 정확히 통하는 양수 분포는 로그정규 하나뿐** 이라는 것이다. 나머지 모든 자료에서 Box-Cox 가 하는 일은 보기 1 의 풀이가 말한 대로 "주어진 계열 안에서 가장 덜 나쁜 $\lambda$" 를 고르는 것이고, 가장 덜 나쁜 것이 좋다는 보장은 없다.

    「정리하며」가 박스–콕스를 **양수 자료에만** 쓸 수 있다고 적고 0 이나 음수가 섞이면 여–존슨으로 간다고 적은 것은 같은 유계성의 다른 면이다. 지지집합이 양의 반직선이라는 사실이 이 변환을 쓸 수 있는 자리를 정하고, 동시에 이 변환이 끝내 도달할 수 없는 곳도 정한다. 그래서 변환의 목표는 "정확한 정규" 가 아니라 "쓸 만큼 가까운 정규" 여야 하며, 그조차 안 되는 자료를 위해 다음 절의 붓스트랩과 비모수 방법이 있다.

## 정리하며

변환은 **자료를 정규에 가깝게 만드는** 가장 직접적인 대처다.

- **로그는 오른쪽 치우침에 쓴다.** 곱셈적 구조를 덧셈적으로 바꾸므로 소득·가격·시간 자료에 잘 맞으며, 분산도 함께 안정된다.
- **제곱근은 계수 자료에 맞는다.** 포아송류에서 분산이 평균에 비례하므로 제곱근이 분산을 안정시킨다.
- **역수는 매우 강한 변환이다.** 극단적인 치우침에만 쓰며 순서가 뒤집힌다.
- **박스–콕스가 이들을 하나로 묶는다.** $\lambda$ 를 자료에서 추정하며 $\lambda=0$ 이 로그, $0.5$ 가 제곱근, $1$ 이 변환 없음이다. **양수 자료에만 쓸 수 있고**, 0 이나 음수가 있으면 여-존슨 변환으로 간다.
- **대가는 해석이다.** 로그 척도의 평균을 되돌리면 평균이 아니라 **중앙값**이 되며(4장), 계수의 뜻도 "배수 변화"로 바뀐다. **무엇을 얻고 무엇을 잃는지 따져야 한다.**
