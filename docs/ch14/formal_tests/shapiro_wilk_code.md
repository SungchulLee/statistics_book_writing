# Shapiro-Wilk 검정

## 개요

Shapiro-Wilk 검정은 작은 표본과 중간 표본에서 가장 강력한 정규성 검정으로 널리 인정받는다. 정렬된 표본값이 기대되는 정규 순서통계량과 얼마나 잘 맞는지를 재어 0과 1 사이의 통계량 $W$를 만든다. $W$가 1에 가까우면 정규성과 일관되고, 유의하게 작으면 기각으로 이어진다. SciPy는 $n \leq 5000$으로 검정을 제한한다.

---

## 1. 검정통계량

순서통계량 $X_{(1)} \leq X_{(2)} \leq \cdots \leq X_{(n)}$이 주어졌을 때 Shapiro-Wilk 통계량은

$$
W = \frac{\left(\sum_{i=1}^{n} a_i\, X_{(i)}\right)^2}{\sum_{i=1}^{n} (X_i - \bar{X})^2},
$$

여기서 계수 $a_1, \ldots, a_n$은 정규 순서통계량의 기댓값과 공분산행렬에서 유도된다. 구체적으로 $m = (m_1, \ldots, m_n)^\top$를 표준정규 순서통계량의 기댓값 벡터, $V$를 그 공분산행렬이라 하면

$$
a = \frac{V^{-1} m}{(m^\top V^{-1} V^{-1} m)^{1/2}}.
$$

이 정규화에 의해 $\sum_i a_i^2 = 1$이다. 또한 $m$이 반대칭이므로($m_i = -m_{n+1-i}$) $a$도 반대칭이고 따라서 $\sum_i a_i = 0$이다. 두 성질 모두 뒤에서 쓰인다.

---

## 2. 직관

분자 $(\sum a_i X_{(i)})^2$은 순서통계량의 가중 선형결합으로, 정규성 아래에서 분모(총제곱합)를 가깝게 따라가야 한다. 자료가 정규이면 정렬된 값들이 기대 정규 순서통계량과 잘 정렬되어 $W \approx 1$이 된다. 치우침, 두꺼운 꼬리, 다봉성 같은 정규성 이탈은 이 정렬을 깨뜨려 $W$를 줄인다.

---

## 3. 가설

$$
H_0: X_1, \ldots, X_n \sim \mathcal{N}(\mu, \sigma^2), \qquad H_1: \text{자료가 정규분포를 따르지 않는다}.
$$

$W$가 작으면(동등하게 $p$값이 작으면) $H_0$을 기각한다.

    | 성분 | 통계량 | $p$값 |
    |---|---|---|
    | 왜도 검정 | $Z_1 = 2.5915$ | $0.00956$ |

    이다. 둘 다 $\alpha = 0.05$에서 기각하지만 첨도 쪽 $p$값이 **백 배** 작다. 대수정규 오염이 치우침과 두꺼운 꼬리를 동시에 들여왔는데, $n = 300$에서 잡히는 신호는 꼬리 쪽이 훨씬 강하다. 샤피로–윌크의 $p = 4.27\times10^{-5}$가 첨도 검정의 $8.27\times10^{-5}$와 같은 자릿수인 것도 그에 맞는다.

    **요약통계만으로는 이 판정을 할 수 없다.** $g_1 = 0.37$과 $g_2 = 1.86$을 나란히 놓고 "첨도가 더 크다"고 말하는 것은 단위가 다른 두 수를 비교하는 것이어서 의미가 없다. 각각을 자기 표준오차로 재어 $Z$로 바꾸어야 비교가 성립한다.

    **(2) $n = 300$에서 $W$의 귀무분포가 $[0.976,\ 1]$ 안에 갇혀 있다.** 2만 번 뽑아 재면

    | 백분위 | 0.1% | 1% | 5% | 50% | 최솟값 |
    |---|---|---|---|---|---|
    | $W$ | $0.98279$ | $0.98713$ | $0.99052$ | $0.99528$ | $0.97602$ |

    이다. 5% 기각 경계가 $0.99052$로 1에서 $0.0095$ 떨어져 있을 뿐이다. 관측값 $W = 0.97497$은 1에서 $0.0250$ 떨어져 있으니 **그 거리의 $2.64$배**다.

    더 극적인 것은 관측값이 **2만 개 모의값 전부보다 작다**는 사실이다. 귀무분포의 최솟값이 $0.97602$인데 관측값이 $0.97497$이다. 곧 모의실험이 줄 수 있는 답은 $p < 1/20000 = 5\times10^{-5}$이고, `scipy`가 돌려준 $4.27\times10^{-5}$가 그와 맞아떨어진다.

    **급강하의 정체는 이것이다.** $W$가 사는 구간이 $n$과 함께 1 쪽으로 쪼그라들므로, $W$의 눈금 $0.001$이 큰 표본에서는 엄청난 양의 증거가 된다. $0.9986$과 $0.9750$의 차이는 "$0.024$ 차이"가 아니라 **귀무분포의 폭으로 재면 자릿수를 건너뛰는 차이**다. 앞 쪽에서 본 결론이 여기서 되풀이된다. $W$ 값을 눈으로 읽지 말고 $p$값을 읽어야 한다.

    ```python
    import numpy as np
    from scipy import stats

    # 정규 240개에 로그정규 60개를 섞은 자료다.
    rng = np.random.default_rng(0)
    x = np.concatenate([rng.normal(0, 1, size=240),
                        rng.lognormal(0, 0.6, size=60)])

    W, p = stats.shapiro(x)

    # 검정은 "정규가 아니다"까지만 말한다. 무엇이 문제인지는 왜도와 첨도가
    # 알려 준다. 그래서 검정 결과와 늘 함께 본다.
    g1 = stats.skew(x, bias=False)
    g2 = stats.kurtosis(x, fisher=True, bias=False)

    print(f"Sample size n = {x.size}")
    print(f"Shapiro-Wilk: W = {W:.4f}, p-value = {p:.4g}")
    print(f"Skewness g1 = {g1:.4f}, Excess kurtosis g2 = {g2:.4f}")
    if p < 0.05:
        print("=> Reject normality at alpha = 0.05.")
    else:
        print("=> Fail to reject normality at alpha = 0.05.")
    ```

    출력:

    ```text
    Sample size n = 300
    Shapiro-Wilk: W = 0.9750, p-value = 4.27e-05
    Skewness g1 = 0.3707, Excess kurtosis g2 = 1.8565
    => Reject normality at alpha = 0.05.
    ```

    두 성분의 검정과 $W$의 귀무분포를 함께 구한다.

    ```python
    import numpy as np
    from scipy import stats

    rng = np.random.default_rng(0)
    x = np.concatenate([rng.normal(0, 1, size=240),
                        rng.lognormal(0, 0.6, size=60)])
    n = x.size
    W, p = stats.shapiro(x)
    print(f"W = {W:.6f},  p = {p:.4g}")

    # 기각의 범인은 치우침인가 꼬리인가 — 두 성분을 따로 본다.
    z1, p1 = stats.skewtest(x)
    z2, p2 = stats.kurtosistest(x)
    print(f"\n왜도 검정   Z1 = {z1:.4f}, p = {p1:.4g}")
    print(f"첨도 검정   Z2 = {z2:.4f}, p = {p2:.4g}")
    print(f"비보정 g1 = {stats.skew(x):.4f}, g2 = {stats.kurtosis(x):.4f}")
    print(f"보정   G1 = {stats.skew(x, bias=False):.4f}, G2 = {stats.kurtosis(x, bias=False):.4f}")

    # n = 300 에서 W 의 귀무분포
    rng2 = np.random.default_rng(9)
    R = 20_000
    Wn = np.array([stats.shapiro(rng2.standard_normal(n))[0] for _ in range(R)])
    q = np.percentile(Wn, [0.1, 1, 5, 50])
    print(f"\nn = {n} 에서 W 의 귀무분포 (R = {R})")
    print(f"  0.1 백분위 {q[0]:.5f},  1 백분위 {q[1]:.5f},  5 백분위 {q[2]:.5f},  중앙값 {q[3]:.5f}")
    print(f"  관측 W = {W:.5f} 보다 작은 모의값의 비율 = {np.mean(Wn < W):.5f}  ({np.sum(Wn < W)}/{R})")
    print(f"  귀무분포의 최솟값 = {Wn.min():.5f}")
    print(f"  5 백분위와 1 의 거리 = {1 - q[2]:.5f},  관측 W 와 1 의 거리 = {1 - W:.5f}"
          f"  (비 {(1 - W) / (1 - q[2]):.2f})")
    ```

    출력:

    ```text
    W = 0.974974,  p = 4.27e-05

    왜도 검정   Z1 = 2.5915, p = 0.009556
    첨도 검정   Z2 = 3.9365, p = 8.266e-05
    비보정 g1 = 0.3688, g2 = 1.8058
    보정   G1 = 0.3707, G2 = 1.8565

    n = 300 에서 W 의 귀무분포 (R = 20000)
      0.1 백분위 0.98279,  1 백분위 0.98713,  5 백분위 0.99052,  중앙값 0.99528
      관측 W = 0.97497 보다 작은 모의값의 비율 = 0.00000  (0/20000)
      귀무분포의 최솟값 = 0.97602
      5 백분위와 1 의 거리 = 0.00948,  관측 W 와 1 의 거리 = 0.02503  (비 2.64)
    ```

    모의실험이 `scipy`의 $p$값을 위에서 묶어 준다. 2만 번 가운데 관측값보다 작은 $W$가 **하나도 없으므로** 경험적 $p$값은 $5\times10^{-5}$ 미만이고, 보고된 $4.27\times10^{-5}$가 그 안에 들어온다. $\square$

---

## 4. 강점과 한계

**강점:**

- $n \leq 5000$에서 흔히 쓰는 정규성 검정 중 검정력이 가장 높다.
- 폭넓은 대립가설(치우침, 첨도, 다봉성)에 민감하다.
- 임계값과 $p$값 근사가 잘 확립되어 있다.

**한계:**

- SciPy는 $n > 5000$에서 $p$값이 부정확할 수 있다고 경고한다.
- $n$이 아주 크면 사소한 이탈에도 기각한다. 이때는 시각적 방법과 효과 크기가 더 유익하다.
- 이탈의 *유형*을 알려주지 않는다(진단에는 Q-Q 그림과 짝지어 쓰라).

## 5. 해석

혼합 보기에서 대수정규 성분이 치우침과 두꺼운 꼬리를 들여온다. $W = 0.975$로 1보다 뚜렷하게 작고 $p = 4.3 \times 10^{-5}$이다.

$W = 0.975$가 "1에 가깝다"고 느껴질 수 있으나, $W$의 척도는 그렇게 읽으면 안 된다. 정규자료 $n = 300$에서 $W$의 귀무분포는 0.99 근처에 매우 좁게 몰려 있으므로 $0.975$는 상당히 작은 값이다. $W$와 함께 보조 요약값($g_1 = 0.37$, $g_2 = 1.86$)을 보고하면 왜 정규성이 기각되었는지(주로 두꺼운 꼬리) 독자가 이해할 수 있다.

### W에는 고정된 눈금이 없다

"$W$가 얼마면 정규인가"라는 물음에는 답이 없다. $W$의 귀무분포 자체가 $n$에 따라 움직이기 때문이다. 아래 그림은 진짜 정규자료에서 $W$를 30000번 계산한 분포를 $n = 30$과 $n = 300$에 대해 같은 가로축 위에 그린 것이다. 빨간 선은 앞 보기에서 얻은 $W = 0.975$이다.

![표본크기 30과 300에서 W의 귀무분포를 비교하고 W=0.975의 위치를 표시한 그림](./img/shapiro_null_scale.png)

$n = 30$에서 귀무분포는 중앙값 $0.9684$를 중심으로 $0.88$까지도 흔하게 퍼져 있다. 5백분위 — 곧 5% 수준의 임계값 — 가 $0.9307$이므로 $W = 0.975$는 기각과 거리가 멀다. 정규자료의 $68.5\%$가 이보다 작은 $W$를 낸다. 이 표본크기에서 $0.975$는 "아주 평범한 정규 표본"이라는 뜻이다.

$n = 300$에서는 같은 분포가 $0.99$ 근처로 오그라든다. 중앙값 $0.9953$, 5백분위 $0.9906$이다. 정규자료 30000개 표본 가운데 $W < 0.975$인 것은 **단 하나도 없었다**. 같은 $0.975$가 여기서는 극단값이 되고, 실제로 보기의 $p$값은 $4.3 \times 10^{-5}$이다.

왜 이런 일이 일어나는가. $W$는 Q-Q 그림의 직선성을 재는데, 표본이 커지면 정규자료의 순서통계량이 정규 점수에 점점 정확하게 정렬된다. 그래서 $W$가 $1$로 수렴하고 그 주위의 흔들림도 $n$이 커지는 만큼 줄어든다. 임계값이 $1$ 쪽으로 밀려 올라가는 것이다. 이것이 이 장에서 되풀이해 만나게 될 현상의 첫 모습이다. **표본이 커지면 정규성 검정은 점점 더 작은 이탈에도 반응한다.** $W$ 값을 보고할 때는 반드시 $n$을 함께 적어야 하고, 다른 표본크기에서 얻은 $W$끼리 크기를 비교해서는 안 된다.

??? success "풀이"

    ```python
    import numpy as np
    from scipy import stats

    rng = np.random.default_rng(0)
    W_values, p_values = [], []
    for trial in range(20):
        x = rng.normal(0, 1, size=100)
        W, p = stats.shapiro(x)
        W_values.append(W)
        p_values.append(p)

    print(f"W range: [{min(W_values):.4f}, {max(W_values):.4f}]")
    print(f"Mean W: {np.mean(W_values):.4f}")
    print(f"Rejections at 0.05: {sum(p < 0.05 for p in p_values)} / 20")
    ```

    출력:

    ```text
    W range: [0.9714, 0.9950]
    Mean W: 0.9847
    Rejections at 0.05: 3 / 20
    ```

    $n = 100$인 정규자료에서 $W$는 $0.971$~$0.995$ 범위에 있고 평균은 $0.985$이다. $W$가 1에 매우 가까운 좁은 구간에 몰린다는 점이 중요하다. $W = 0.97$은 "거의 1"이 아니라 이미 분포의 아래쪽 꼬리에 있다.

    !!! warning "20회 중 3회가 기각되었다"
        자료가 모두 참으로 정규인데도 세 번(시행 2, 3, 4번)이 $\alpha = 0.05$에서 기각했다. 기댓값은 $20 \times 0.05 = 1$회이므로 3회는 많은 편이다. 이항분포로 계산하면 $P(X \geq 3) = 0.075$이니 놀랄 일까지는 아니고 우연의 범위 안이다.

        더 중요한 교훈은 **다중검정**이다. 20번의 독립 검정에서 적어도 한 번 잘못 기각할 확률은

        $$
        1 - 0.95^{20} = 0.64
        $$

        로 64%에 이른다. 여러 변수나 여러 집단에 정규성 검정을 반복 적용할 때는 이 점을 반드시 고려해야 한다. 다중비교 보정 없이 "어느 집단 하나가 정규성 검정에 실패했다"고 결론짓는 것은 위험하다. $\square$

    ```python
    import numpy as np
    from scipy import stats

    rng = np.random.default_rng(42)
    distributions = {
        "N(0,1)": rng.normal(0, 1, 50),
        "t(5)": rng.standard_t(5, 50),
        "Lognormal(0,0.5)": rng.lognormal(0, 0.5, 50),
        "Uniform(0,1)": rng.uniform(0, 1, 50),
    }

    for name, x in distributions.items():
        W, p = stats.shapiro(x)
        print(f"{name:>20}: W = {W:.4f}, p = {p:.4g}")
    ```

**연습문제 3.** <span class="diff med" title="중간"></span> 항상 $W \leq 1$이 성립하는 이유를 설명하라. 어떤 조건에서 $W = 1$이 정확히 성립하는가?

</div>

??? success "풀이"

    핵심은 계수 $a$의 두 성질이다. $\sum_i a_i = 0$이고 $\sum_i a_i^2 = 1$이다.

    첫 번째 성질에서 $\sum_i a_i \bar{X} = 0$이므로 분자를 중심화된 형태로 다시 쓸 수 있다.

    $$
    \sum_{i=1}^n a_i X_{(i)} = \sum_{i=1}^n a_i \bigl(X_{(i)} - \bar{X}\bigr).
    $$

    이제 Cauchy-Schwarz 부등식을 적용한다.

    $$
    \left(\sum_i a_i (X_{(i)} - \bar{X})\right)^2 \leq \left(\sum_i a_i^2\right)\left(\sum_i (X_{(i)} - \bar{X})^2\right) = \sum_i (X_i - \bar{X})^2.
    $$

    마지막 등호는 $\sum a_i^2 = 1$이고 정렬은 제곱합을 바꾸지 않기 때문이다. 양변을 $\sum (X_i - \bar{X})^2$으로 나누면 $W \leq 1$을 얻는다.

    **등호 조건.** Cauchy-Schwarz의 등호는 두 벡터가 평행할 때, 곧 어떤 상수 $c$에 대해

    $$
    X_{(i)} - \bar{X} = c\, a_i \quad (\forall i)
    $$

    일 때 성립한다. 곧 중심화된 정렬 자료가 계수 벡터 $a$의 정확한 배수여야 한다.

    연속형 자료에서 이 사건의 확률은 0이므로 $W = 1$은 실제로 관측되지 않는다. $W$는 1보다 엄격히 작되 정규자료에서는 1에 매우 가깝다. $\square$

**연습문제 4.** <span class="diff med" title="중간"></span> $t_5$ 분포에서 뽑은 관측값 $n = 50$개에 대해 Shapiro-Wilk 검정과 ($\mathcal{N}(0,1)$에 대한) KS 검정의 검정력을 비교하는 몬테카를로 연구를 수행하라.

</div>

??? success "풀이"

    ```python
    import numpy as np
    from scipy import stats

    rng = np.random.default_rng(0)
    n, reps, alpha = 50, 5000, 0.05
    rej_sw, rej_ks = 0, 0

    for _ in range(reps):
        x = rng.standard_t(df=5, size=n)
        _, p_sw = stats.shapiro(x)
        _, p_ks = stats.kstest(x, 'norm', args=(0, 1))
        if p_sw < alpha:
            rej_sw += 1
        if p_ks < alpha:
            rej_ks += 1

    print(f"Shapiro-Wilk power: {rej_sw / reps:.4f}")
    print(f"KS power:           {rej_ks / reps:.4f}")
    ```

    출력:

    ```text
    Shapiro-Wilk power: 0.3616
    KS power:           0.0622
    ```

    Shapiro-Wilk의 검정력 $0.362$가 KS의 $0.062$보다 **약 5.8배** 높다. 두꺼운 꼬리 대립가설에 대해 가장 강력한 범용 정규성 검정이라는 평판을 확인해 준다.

    두 숫자를 해석할 때 주의할 점이 있다.

    - KS의 $0.062$는 명목 크기 $0.05$보다 겨우 조금 클 뿐이다. 사실상 **탐지 능력이 없다**. 완전히 지정된 $\mathcal{N}(0,1)$에 대한 검정임에도 그렇다.
    - Shapiro-Wilk의 $0.362$도 절대 기준으로는 높지 않다. $t_5$ 표본의 **64%를 놓친다**. 초과첨도가 6인 분포인데도 $n = 50$으로는 부족하다는 뜻이다.

    실무적 교훈: 작은 표본에서 정규성 검정이 기각하지 못했다고 해서 안심해서는 안 된다. 검정력이 낮아서일 가능성이 크다. $\square$

**연습문제 5.** <span class="diff med" title="중간"></span> 큰 표본에서는 자료가 정규성에서 조금만 벗어나도 Shapiro-Wilk 검정이 유의하지 않게 나오기가 거의 불가능하다. 이런 상황에서 $p$값보다 $W$ 통계량 자체를 (효과 크기로) 보고하는 편이 더 유익한 이유를 논하라.

</div>

??? success "풀이"

    $n$이 커지면 Shapiro-Wilk 검정의 검정력이 점점 커진다. $H_0$ 아래에서 $W$의 분산이 줄어들고, 아주 작은 이탈(예: $\gamma_2 = 0.1$)만으로도 $W$가 임계값 아래로 안정적으로 떨어진다. 정규가 아닌 어떤 분포든, 정규에 아무리 가깝든 $p$값이 0으로 간다. 그러면 $p$값이 실용적으로 무의미해진다. "표본이 이탈을 탐지할 만큼 크다"는 말밖에 해주지 않기 때문이다.

    반면 $W$ 통계량 자체는 이탈의 *크기*를 전달한다. $W = 0.998$이면서 $p < 0.001$이라면, 통계적으로 유의하더라도 자료의 모양이 정규에 극도로 가깝다는 뜻이다. 반대로 $W = 0.92$는 훨씬 실질적인 이탈을 뜻한다.

    $W$를 $g_1$, $g_2$와 함께 보고하면 분석자가 그 편차가 자신의 응용에서 실질적으로 의미 있는지 판단할 수 있다(예: $t$ 검정이 여전히 근사적으로 타당할지).

    척도 감각을 위한 참고: 연습문제 1에서 보았듯 정규자료 $n = 100$에서 $W$는 $0.97$~$0.995$ 범위에 있다. 곧 $W$의 "정상 범위"는 매우 좁으므로 $W = 0.95$처럼 얼핏 1에 가까워 보이는 값도 실은 큰 이탈이다. $W$를 효과 크기로 읽을 때는 이 척도를 염두에 두어야 한다. $\square$

**연습문제 6.** <span class="diff med" title="중간"></span> 1 절은 계수 $a$ 가 $\sum_i a_i = 0$, $\sum_i a_i^2 = 1$ 을 만족하고 반대칭성 $a_i = -a_{n+1-i}$ 까지 가진다고 했다. 연습문제 3 은 앞의 두 성질로 $W \leq 1$ 을 얻었다. 여기서는 세 성질이 함께 $W$ 의 또 다른 쓸모를 낳는 것을 본다.

**(1)** $\beta > 0$ 일 때 $Y_i = \alpha + \beta X_i$ 로 자료를 바꾸어도 $W$ 가 변하지 않음을 보이시오.

**(2)** $\beta < 0$ 이면 정렬 순서가 뒤집혀 $Y_{(i)} = \alpha + \beta X_{(n+1-i)}$ 가 된다. 1 절의 반대칭성 $a_i = -a_{n+1-i}$ 를 써서 이때도 $W$ 가 변하지 않음을 보이시오.

**(3)** 5 절의 귀무분포 모의는 모두 `rng.standard_normal(n)` 으로 돌렸다. (1) 을 근거로, 거기서 얻은 임계값 $0.9307$ ($n = 30$) 과 $0.9906$ ($n = 300$) 을 평균 $\mu$ 와 분산 $\sigma^2$ 가 무엇이든 그대로 쓸 수 있는 까닭을 말하시오. 이 성질이 없었다면 임계값 표를 어떻게 만들어야 했겠는가.

</div>

??? success "풀이"

    **(1)** $\beta > 0$ 이면 정렬 순서가 보존되어 $Y_{(i)} = \alpha + \beta X_{(i)}$ 이고 $\bar{Y} = \alpha + \beta \bar{X}$ 다. 분자의 선형결합은

    $$
    \sum_{i=1}^n a_i Y_{(i)} = \alpha \sum_{i=1}^n a_i + \beta \sum_{i=1}^n a_i X_{(i)} = \beta \sum_{i=1}^n a_i X_{(i)}
    $$

    이다. 평행이동 $\alpha$ 가 통째로 사라진 것은 오직 $\sum_i a_i = 0$ 때문이다. 분모는

    $$
    \sum_{i=1}^n (Y_i - \bar{Y})^2 = \sum_{i=1}^n \bigl(\beta (X_i - \bar{X})\bigr)^2 = \beta^2 \sum_{i=1}^n (X_i - \bar{X})^2
    $$

    이므로 분자의 $\beta^2$ 과 약분되어 $W(Y) = W(X)$ 다.

    **(2)** $\beta < 0$ 이면 분자의 둘째 항에서 $j = n + 1 - i$ 로 치환한다.

    $$
    \sum_{i=1}^n a_i X_{(n+1-i)} = \sum_{j=1}^n a_{n+1-j} X_{(j)} = -\sum_{j=1}^n a_j X_{(j)}.
    $$

    마지막 등호가 반대칭성이다. 따라서 $\sum_i a_i Y_{(i)} = -\beta \sum_j a_j X_{(j)}$ 이고 제곱하면 부호가 사라져 분자는 $\beta^2 \bigl(\sum a_i X_{(i)}\bigr)^2$ 로 (1) 과 같다. 분모도 $\beta^2$ 배이므로 $W$ 는 또 변하지 않는다. 곧 $W$ 는 $\beta \neq 0$ 인 **모든** 아핀변환에 대해 불변이다.

    **(3)** $X_i \sim \mathcal{N}(\mu, \sigma^2)$ 일 때 $\alpha = -\mu/\sigma$, $\beta = 1/\sigma > 0$ 을 (1) 에 넣으면

    $$
    W(X_1, \ldots, X_n) = W\!\left(\frac{X_1 - \mu}{\sigma}, \ldots, \frac{X_n - \mu}{\sigma}\right)
    $$

    이고 오른쪽 자료는 정확히 표준정규다. 곧 $H_0$ 아래에서 $W$ 의 분포는 $(\mu, \sigma^2)$ 에 전혀 의존하지 않고 **$n$ 에만** 의존한다. 그래서 `standard_normal` 로 한 번 만든 $0.9307$, $0.9906$ 이 섭씨로 잰 자료든 달러로 잰 자료든 그대로 통한다.

    불변성이 없었다면 $(\mu, \sigma^2)$ 쌍마다 다른 임계값 표가 필요하고, $\mu$ 와 $\sigma$ 를 모르는 실제 상황에서는 $\bar{X}$ 와 $s$ 를 꽂은 뒤 **그 추정 때문에 달라진** 귀무분포를 새로 구해야 했을 것이다. 샤피로–윌크는 표준화를 통계량 안에 품고 있어서 그 대가를 치르지 않는다. 5 절이 "$W$ 의 귀무분포 자체가 $n$ 에 따라 움직인다"고만 말하고 $\mu, \sigma$ 를 언급하지 않은 근거가 바로 이것이다. $\square$

**연습문제 7.** <span class="diff med" title="중간"></span> 5 절은 "$W$ 가 사는 구간이 $n$ 과 함께 1 쪽으로 쪼그라든다"고 했고, 보기 1 은 $n = 300$ 에서 5 백분위와 1 의 거리가 $0.00948$ 임을 보였다. 그 쪼그라드는 **속도**를 재자.

**(1)** $n = 25, 50, 100, 200, 400, 800$ 에서 귀무분포의 5 백분위 $q_{0.05}(n)$ 을 모의로 구하고, $1 - q_{0.05}(n)$ 에 $n$ 을 곱한 열과 $\sqrt{n}$ 을 곱한 열을 나란히 만드시오. 둘 중 어느 쪽이 유계로 남는가.

**(2)** (1) 에서 $1 - q_{0.05}(n) \approx c/n$ 을 읽어내고, $n = 800$ 에서 읽은 $c$ 로 $n = 2000$ 의 임계값을 외삽한 뒤 직접 모의한 값과 비교하시오.

**(3)** KS 통계량의 임계값은 $1/\sqrt{n}$ 으로 줄어든다. $1 - W$ 쪽이 한 차수 빠른 $1/n$ 인 까닭을 연습문제 3 의 코시–슈바르츠 등식조건에서 설명하시오.

</div>

??? success "풀이"

    ```python
    import numpy as np
    from scipy import stats

    rng = np.random.default_rng(0)
    R = 8000
    ns = [25, 50, 100, 200, 400, 800]

    print(f"{'n':>5} {'q05(W)':>9} {'1-q05':>9} {'n(1-q05)':>10} {'sqrt(n)(1-q05)':>16}")
    d05 = []
    for n in ns:
        W = np.array([stats.shapiro(rng.standard_normal(n))[0] for _ in range(R)])
        q = np.percentile(W, 5)
        d05.append(1 - q)
        print(f"{n:>5} {q:>9.5f} {1-q:>9.6f} {n*(1-q):>10.3f} {np.sqrt(n)*(1-q):>16.4f}")

    slope = np.polyfit(np.log(ns), np.log(d05), 1)[0]
    print(f"\nlog(1-q05) 대 log n 의 기울기 = {slope:.3f}")

    c800 = 800 * d05[-1]
    pred = 1 - c800 / 2000
    W2 = np.array([stats.shapiro(rng.standard_normal(2000))[0] for _ in range(R)])
    q2 = np.percentile(W2, 5)
    print(f"n = 800 의 상수 c = {c800:.3f} 로 외삽한 n = 2000 의 q05 = {pred:.5f}")
    print(f"n = 2000 을 직접 모의한 q05 = {q2:.5f}   (n(1-q05) = {2000*(1-q2):.3f})")
    ```

    출력:

    ```text
        n    q05(W)     1-q05   n(1-q05)   sqrt(n)(1-q05)
       25   0.91946  0.080539      2.013           0.4027
       50   0.95431  0.045690      2.284           0.3231
      100   0.97439  0.025609      2.561           0.2561
      200   0.98626  0.013743      2.749           0.1944
      400   0.99280  0.007204      2.882           0.1441
      800   0.99630  0.003702      2.962           0.1047

    log(1-q05) 대 log n 의 기울기 = -0.889
    n = 800 의 상수 c = 2.962 로 외삽한 n = 2000 의 q05 = 0.99852
    n = 2000 을 직접 모의한 q05 = 0.99842   (n(1-q05) = 3.163)
    ```

    **(1) $n$ 을 곱한 열이 유계다.** $n$ 이 $25$ 에서 $800$ 으로 **32 배** 커지는 동안 $n(1 - q_{0.05})$ 은 $2.013$ 에서 $2.962$ 로 $1.5$ 배 안에서 천천히 올라갈 뿐이고, 더 밀어 $n = 2000$ 에서도 $3.163$ 이다. 반면 $\sqrt{n}(1 - q_{0.05})$ 은 $0.4027$ 에서 $0.1047$ 로 거의 **4 배 줄어든다** — 곧 $1 - q_{0.05}$ 는 $1/\sqrt{n}$ 보다 훨씬 빠르게 사라진다. $\log$–$\log$ 기울기 $-0.889$ 도 $-1$ 쪽이지 $-0.5$ 쪽이 아니다. 기울기가 $-1$ 에 정확히 닿지 않는 것은 $n(1-q_{0.05})$ 이 극한값(대략 $3.2$ 근처)으로 **아래에서** 느리게 올라오는 중이기 때문이다.

    **(2)** $n = 800$ 에서 $c = 800 \times 0.003702 = 2.962$ 다. 이것으로 외삽하면

    $$
    q_{0.05}(2000) \approx 1 - \frac{2.962}{2000} = 0.99852
    $$

    이고 직접 모의한 값은 $0.99842$ 다. $W$ 자체의 오차가 $0.0001$ 이니 $1/n$ 법칙은 2.5 배의 외삽을 거의 정확히 견딘다. 상수 $c$ 가 아직 커지는 중이라 예측이 약간 **위로** 치우치는데, 이는 (1) 에서 본 느린 상승과 방향이 맞는다.

    **(3)** 연습문제 3 의 코시–슈바르츠를 각도로 적으면 선명하다. $\|a\| = 1$ 이므로 $u = (X_{(i)} - \bar{X})_i$ 와 $a$ 사이의 각 $\theta$ 에 대해

    $$
    W = \frac{\langle a, u\rangle^2}{\|a\|^2 \|u\|^2} = \cos^2\theta, \qquad 1 - W = \sin^2\theta.
    $$

    곧 $1 - W$ 는 Q-Q 직선에서 벗어난 각의 **제곱**이다. 정규자료에서 정렬된 값이 정규점수에 맞춰지는 오차는 다른 모든 적합 문제와 마찬가지로 $\theta = O_p(n^{-1/2})$ 인데, $W$ 는 그것을 제곱해서 재므로 $1 - W = O_p(n^{-1})$ 이 된다. KS 통계량 $\sup_x \lvert F_n(x) - \Phi(x) \rvert$ 는 거리를 **제곱하지 않고** 그대로 재므로 $n^{-1/2}$ 에 머문다. 같은 $n^{-1/2}$ 짜리 흔들림을 한쪽은 1 제곱, 한쪽은 2 제곱으로 읽는 차이가 전부다.

    이것이 5 절의 경고를 정량화한다. $W$ 의 창이 $1/n$ 로 닫히므로 $n$ 을 10 배 늘리면 유의하다고 판정되는 이탈의 크기는 $10$ 배 작아진다. $\square$

**연습문제 8.** <span class="diff hard" title="어려움"></span> 2 절은 정규성 이탈이 "정렬을 깨뜨려 $W$ 를 줄인다"고 했다. 그렇다면 한 점을 무한히 멀리 보내면 $W$ 가 0 으로 갈 것 같다. 확인해 보자. 자료가 $X_1 = \cdots = X_{n-1} = 0$, $X_n = t > 0$ 이라 하자.

**(1)** 1 절의 $\sum_i a_i = 0$ 을 써서

$$
W = \frac{n}{n-1}\,a_n^2
$$

임을 보이시오. 특히 $W$ 가 $t$ 에 **전혀** 의존하지 않음을 지적하고, 왜 그런지 연습문제 6 으로 설명하시오.

**(2)** `scipy` 에 이 배치를 넣으면 $n = 10$ 에서 $W = 0.365721$, $n = 50$ 에서 $0.125428$, $n = 300$ 에서 $0.031926$ 이고 $t$ 를 $10$ 에서 $10^6$ 으로 키워도 소수 여섯째 자리까지 같다. (1) 에서 $a_n$ 을 거꾸로 읽으시오. 또 $m_n = \mathbb{E}[Z_{(n)}] \sim \sqrt{2\ln n}$ 과 $\sum_i m_i^2 \approx n$ 을 써서 이 하한이 어떤 속도로 0 에 가는지 어림하고, 세 수치로 확인하시오.

**(3)** 연습문제 5 는 $W$ 를 효과 크기로 보고하라고 권했다. (1) 은 그 권고에 어떤 단서를 붙이는가.

</div>

??? success "풀이"

    **(1)** $\bar{X} = t/n$ 이고 정렬된 자료는 $X_{(1)} = \cdots = X_{(n-1)} = 0$, $X_{(n)} = t$ 다. 중심화하면

    $$
    X_{(i)} - \bar{X} = -\frac{t}{n} \ (i \leq n-1), \qquad X_{(n)} - \bar{X} = \frac{(n-1)t}{n}.
    $$

    연습문제 3 의 중심화 형태와 $\sum_{i \leq n-1} a_i = -a_n$ 을 쓰면 분자의 선형결합은

    $$
    \sum_{i=1}^n a_i (X_{(i)} - \bar{X}) = -\frac{t}{n}\sum_{i \leq n-1} a_i + a_n \frac{(n-1)t}{n} = \frac{t a_n}{n} + \frac{(n-1) t a_n}{n} = t\,a_n
    $$

    이다. 분모는

    $$
    \sum_{i=1}^n (X_i - \bar{X})^2 = (n-1)\frac{t^2}{n^2} + \frac{(n-1)^2 t^2}{n^2} = \frac{(n-1)t^2}{n^2}\bigl(1 + (n-1)\bigr) = \frac{(n-1)t^2}{n}
    $$

    이므로

    $$
    W = \frac{t^2 a_n^2}{(n-1)t^2/n} = \frac{n}{n-1}a_n^2.
    $$

    $t$ 가 약분된 것은 분자와 분모가 모두 $t$ 의 2 차 동차식이기 때문이다. 더 근본적으로, 이 배치에서 $t$ 를 바꾸는 일은 자료 전체에 $\beta = t'/t$ 를 곱하는 **순수한 척도변환**이고, 연습문제 6 에 따라 $W$ 는 그런 변환에 불변이다. 곧 $W$ 가 $t$ 에 둔감한 것은 결함이 아니라 불변성의 필연적 대가다.

    **(2)** $a_n = \sqrt{W(n-1)/n}$ 로 거꾸로 읽으면

    | $n$ | $W$ | $a_n$ | 어림 $m_n^2/n$ |
    |---|---|---|---|
    | $10$ | $0.365721$ | $0.573715$ | $0.2365$ |
    | $50$ | $0.125428$ | $0.350599$ | $0.1011$ |
    | $300$ | $0.031926$ | $0.178381$ | $0.0276$ |

    이다. 큰 $n$ 에서 $a \approx m/\lVert m \rVert$ 이고 $\lVert m \rVert^2 = \sum_i m_i^2 \approx n$ 이므로

    $$
    W_{\min} = \frac{n}{n-1}a_n^2 \approx \frac{m_n^2}{n} \approx \frac{2\ln n}{n} \to 0,
    $$

    곧 하한은 0 으로 가지만 $1/n$ 이 아니라 $\ln n / n$ 의 느린 속도다. 수치로 확인하면 $n$ 이 $10$ 에서 $300$ 으로 30 배 커질 때 $W$ 는 $0.365721/0.031926 = 11.46$ 배 줄었는데, $\ln n/n$ 법칙이 예측하는 값은

    $$
    \frac{\ln 10 / 10}{\ln 300 / 300} = \frac{0.230259}{0.019013} = 12.11
    $$

    로 잘 맞는다. ($1/n$ 만이라면 30 배여야 하므로 $\ln n$ 보정이 꼭 필요하다.) 이 값이 실제로 주어진 $n$ 에서 $W$ 가 가질 수 있는 **최솟값**임이 알려져 있다.

    **(3) $W$ 는 이상점의 크기를 재지 못한다.** $10\sigma$ 짜리 이상점 하나를 가진 자료와 $10^6\sigma$ 짜리 이상점 하나를 가진 자료가 **똑같은 $W$, 똑같은 $p$ 값**을 낸다. 따라서 $W$ 를 효과 크기로 읽을 때 그것은 "분포의 몸통 모양이 정규선과 얼마나 어긋났는가"를 재는 것이지 "가장 먼 점이 얼마나 먼가"를 재는 것이 아니다. 더구나 $W$ 는 아무리 험한 자료에서도 $\frac{n}{n-1}a_n^2$ 아래로 내려가지 못하므로, 이상점이 지배하는 자료에서는 금방 포화되어 더 나빠지는 것을 보여 주지 못한다.

    실무적으로는 $W$ 와 $g_1, g_2$ 에 더해 **최대 표준화 잔차** $\max_i \lvert X_i - \bar{X} \rvert / s$ 를 함께 보고해야 한다. $\lvert z \rvert$ 는 척도불변이면서도 이상점의 상대적 크기를 그대로 전달한다. $\square$

**연습문제 9.** <span class="diff hard" title="어려움"></span> 4 절은 샤피로–윌크가 "폭넓은 대립가설에 민감하다"고 했다. 적률만 보는 검정과 비교하면 이 말의 무게가 드러난다. 다음 대칭 혼합분포 $M$ 을 생각하자.

$$
M: \quad \tfrac{2}{3}\,\mathcal{N}(0, 3^2) + \tfrac{1}{6}\,\mathcal{N}(-2, 1^2) + \tfrac{1}{6}\,\mathcal{N}(+2, 1^2).
$$

**(1)** $M$ 의 2 차·4 차 중심적률을 손으로 계산해 $\gamma_1 = 0$ 이고 $\gamma_2 = 0$ 임을 **정확히** 보이시오. ($\mathcal{N}(\mu, 1)$ 에 대해 $\mathbb{E}[X^4] = \mu^4 + 6\mu^2 + 3$ 을 쓰라.)

**(2)** $n = 200$ 과 $n = 1000$ 에서 같은 표본에 자크–베라와 샤피로–윌크를 함께 걸어 기각률을 재시오. 참 정규자료의 기각률도 함께 재어 비교 기준으로 삼으시오.

**(3)** 표본을 더 키우면 자크–베라가 결국 $M$ 을 잡아내겠는가. 자크–베라 통계량이 자료의 무엇만 보는지를 들어 답하시오.

</div>

??? success "풀이"

    **(1)** $M$ 은 원점에 대해 대칭이므로 모든 홀수 적률이 0 이고 $\gamma_1 = 0$ 이다. 평균이 0 이니 중심적률은 그냥 원점적률이다. 성분별로

    | 성분 | 가중치 | $\mathbb{E}[X^2]$ | $\mathbb{E}[X^4]$ |
    |---|---|---|---|
    | $\mathcal{N}(0, 3^2)$ | $2/3$ | $9$ | $3 \cdot 3^4 = 243$ |
    | $\mathcal{N}(\pm 2, 1^2)$ | $1/6 + 1/6$ | $2^2 + 1 = 5$ | $2^4 + 6 \cdot 2^2 + 3 = 43$ |

    이므로

    $$
    \mu_2 = \frac{2}{3}\cdot 9 + \frac{1}{3}\cdot 5 = 6 + \frac{5}{3} = \frac{23}{3}, \qquad \mu_4 = \frac{2}{3}\cdot 243 + \frac{1}{3}\cdot 43 = 162 + \frac{43}{3} = \frac{529}{3}.
    $$

    한편

    $$
    3\mu_2^2 = 3\left(\frac{23}{3}\right)^2 = \frac{3 \cdot 529}{9} = \frac{529}{3} = \mu_4
    $$

    이므로 $\gamma_2 = \mu_4/\mu_2^2 - 3 = 0$ 이 **정확히** 성립한다 ($529 = 23^2$ 가 맞춰 준다). 그러나 $M$ 은 정규가 아니다. 넓은 성분 하나에 어깨 둘이 얹혀 있어 분산을 맞춘 정규보다 중심이 패고 $\pm 2$ 근처가 솟는다.

    **(2)** 아래 출력의 밀도비 열이 그 패임과 솟음을 수로 보여 준다.

    ```python
    import numpy as np
    from scipy import stats

    # 혼합 M: 2/3 로 N(0, 3^2), 1/6 씩 N(-2, 1) 과 N(+2, 1)
    def draw_M(rng, n):
        u = rng.random(n)
        x = np.empty(n)
        i0, i1, i2 = u < 2/3, (u >= 2/3) & (u < 5/6), u >= 5/6
        x[i0] = rng.normal(0, 3, i0.sum())
        x[i1] = rng.normal(-2, 1, i1.sum())
        x[i2] = rng.normal(+2, 1, i2.sum())
        return x

    rng = np.random.default_rng(0)

    # (1) 적률: 이론값 mu2 = 23/3, mu4 = 529/3 = 3 mu2^2 이므로 g1 = g2 = 0
    big = draw_M(rng, 2_000_000)
    print(f"mu2: theory {23/3:.5f}  sim {np.mean(big**2):.5f}")
    print(f"mu4: theory {529/3:.5f}  sim {np.mean(big**4):.5f}  (3*mu2^2 = {3*(23/3)**2:.5f})")
    print(f"skew {stats.skew(big):+.5f}   excess kurtosis {stats.kurtosis(big):+.5f}")

    # (2) 그래도 밀도는 정규가 아니다 - 분산을 맞춘 정규와 겹쳐 본다
    sd = np.sqrt(23/3)
    print(f"\n{'y':>5} {'f_M(y)':>10} {'phi(y)':>10} {'ratio':>8}")
    for y in [0.0, 1.0, 2.0, 3.0, 5.0, 8.0]:
        f = (2/3)*stats.norm.pdf(y, 0, 3) + (1/6)*stats.norm.pdf(y, -2, 1) + (1/6)*stats.norm.pdf(y, 2, 1)
        g = stats.norm.pdf(y, 0, sd)
        print(f"{y:>5.1f} {f:>10.5f} {g:>10.5f} {f/g:>8.3f}")

    # (3) 같은 자료에 자크-베라와 샤피로-윌크를 함께 건다
    R, alpha = 6000, 0.05
    print(f"\n{'n':>6} {'data':>8} {'JB rej':>8} {'SW rej':>8}")
    for n in [200, 1000]:
        for label, gen in (("normal", lambda m: rng.standard_normal(m)),
                           ("mix M", lambda m: draw_M(rng, m))):
            rj = rs = 0
            for _ in range(R):
                x = gen(n)
                if stats.jarque_bera(x)[1] < alpha: rj += 1
                if stats.shapiro(x)[1] < alpha: rs += 1
            print(f"{n:>6} {label:>8} {rj/R:>8.4f} {rs/R:>8.4f}")
    ```

    밀도비가 $y = 0$ 에서 $0.740$, $y = 2$ 에서 $1.239$ 다. 중심이 26% 패이고 어깨가 24% 솟은 분포인데도 왜도와 초과첨도는 소수 셋째 자리까지 0 이다.

    기각률은 이렇게 갈린다.

    | $n$ | 자료 | 자크–베라 | 샤피로–윌크 |
    |---|---|---|---|
    | $200$ | 정규 | $0.0452$ | $0.0518$ |
    | $200$ | 혼합 $M$ | $0.0762$ | $\mathbf{0.2155}$ |
    | $1000$ | 정규 | $0.0518$ | $0.0522$ |
    | $1000$ | 혼합 $M$ | $0.1002$ | $\mathbf{0.9145}$ |

    $n = 1000$ 에서 샤피로–윌크는 $0.9145$ 로 거의 매번 잡아내는데 자크–베라는 $0.1002$ 에 머문다. 명목 크기 $0.05$ 의 두 배니 아예 눈이 없는 것은 아니지만, 같은 자료에서 상대 검정력이 **9 배** 차이다.

    **(3) 표본을 키워도 자크–베라는 잡지 못한다.** 자크–베라 통계량

    $$
    JB = \frac{n}{6}\left(g_1^2 + \frac{g_2^2}{4}\right)
    $$

    는 자료를 $g_1$ 과 $g_2$ **두 수로만** 요약한다. 그런데 $M$ 아래에서 $g_1 \to \gamma_1 = 0$, $g_2 \to \gamma_2 = 0$ 이므로 $JB$ 가 커질 재료가 없다. 자크–베라에게 $M$ 은 정규와 구별되지 않는다.

    $n$ 을 키워도 기각률이 $\alpha$ 쪽에 머무는 것이 아니라 $0.10$ 근처의 **상수**에 머무는 것은 다른 이유다. $JB$ 는 $\sqrt{n}\,g_1$ 과 $\sqrt{n}\,g_2$ 의 분산을 정규이론값 $6$ 과 $24$ 로 고정해 쓰는데, $M$ 의 6 차·8 차 적률이 정규와 다르므로 그 참 분산이 $6, 24$ 와 어긋난다. 그 비율만큼 기각률이 $\alpha$ 보다 조금 높은 값에 고정되는 것이다. 실제로 $n = 4000$ 에서 $0.1125$, $n = 20000$ 에서 $0.1055$ 로 늘지 않는다. 곧 자크–베라는 $M$ 에 대해 **일치검정이 아니다** — 검정력이 1 로 가지 않는다.

    이것이 "폭넓은 대립가설에 민감하다"의 진짜 뜻이다. $W$ 는 순서통계량 $n$ 개 전부를 정규점수와 맞춰 보므로 3 차·4 차 적률이 완벽히 맞아도 남는 모양의 어긋남을 본다. 적률 두 개로 자료를 압축하는 검정은 그 어긋남이 들어설 자리를 처음부터 버린 것이다. $\square$

**연습문제 10.** <span class="diff hard" title="어려움"></span> 5 절은 "다른 표본크기에서 얻은 $W$ 끼리 크기를 비교해서는 안 된다"고 했다. 두 연구실이 같은 측정을 보고한다. A 는 $n = 30$ 에 $W = 0.960$, B 는 $n = 400$ 에 $W = 0.990$ 이다.

**(1)** 5 절이 준 $n = 300$ 의 1%·5% 백분위 $0.98713$, $0.99052$ 와 연습문제 7 의 $1 - q_\alpha(n) \approx c_\alpha/n$ 법칙으로 $n = 400$ 의 1%·5% 임계값을 어림하시오.

**(2)** 두 연구실 각각에 대해 $\alpha = 0.05$ 에서 판정하고, 어느 쪽이 정규성을 거스르는 증거를 더 많이 가졌는지 답하시오. 5 절이 준 $n = 30$ 의 중앙값 $0.9684$ 와 5 백분위 $0.9307$ 을 쓰라.

**(3)** "A 의 $W$ 가 더 작으니 A 의 **자료**가 정규에서 더 심하게 벗어난 것이다" 는 말은 왜 성립하지 않는가. 연습문제 7 의 $1 - W = \sin^2\theta$ 를 두 몫으로 나누어 설명하시오.

</div>

??? success "풀이"

    **(1)** 두 꼬리 확률에 대해 각각 상수를 읽는다.

    $$
    c_{0.05} = 300\,(1 - 0.99052) = 2.844, \qquad c_{0.01} = 300\,(1 - 0.98713) = 3.861.
    $$

    $n = 400$ 으로 옮기면

    $$
    q_{0.05}(400) \approx 1 - \frac{2.844}{400} = 0.99289, \qquad q_{0.01}(400) \approx 1 - \frac{3.861}{400} = 0.99035.
    $$

    연습문제 7 의 표가 $n = 400$ 에서 $q_{0.05} = 0.99280$ 을 주었으니 어림이 $0.0001$ 안에서 맞는다. $300 \to 400$ 은 짧은 외삽이어서 $c$ 의 느린 상승이 거의 영향을 주지 않는다.

    **(2) 기각하는 쪽은 B 다.**

    | 연구실 | $n$ | $W$ | 5% 임계값 | 판정 |
    |---|---|---|---|---|
    | A | $30$ | $0.960$ | $0.9307$ | 기각 못 함 |
    | B | $400$ | $0.990$ | $0.99289$ | **기각** |

    A 의 $0.960$ 은 임계값 $0.9307$ 보다 한참 위다. 그뿐 아니라 $n = 30$ 귀무분포의 중앙값 $0.9684$ 보다 겨우 $0.008$ 아래이므로 "아주 평범한 정규 표본" 쪽에 속한다 (모의로 재면 $P(W < 0.960) = 0.31$ 이다). B 의 $0.990$ 은 5% 임계값 $0.99289$ 를 넘어서고 (1) 의 1% 임계값 $0.99035$ 조차 밑돌아 $p < 0.01$ 이다 (모의값은 $p = 0.0078$).

    곧 **$W$ 가 더 큰 쪽이 증거가 더 강하다.** 숫자만 보면 $0.990 > 0.960$ 이니 B 가 더 정규처럼 보이지만, 재는 자가 다르다. A 의 이탈 $1 - W = 0.040$ 은 자기 임계거리 $1 - 0.9307 = 0.0693$ 의 $0.58$ 배뿐이고, B 의 $1 - W = 0.010$ 은 자기 임계거리 $1 - 0.99289 = 0.00711$ 의 $1.41$ 배다. 비교해야 할 것은 $W$ 가 아니라 **$W$ 를 자기 $n$ 의 귀무분포 폭으로 나눈 값**이다.

    **(3)** 연습문제 7 에서 $1 - W = \sin^2\theta$ 였다. 모수적으로 고정된 어떤 비정규 분포에서 뽑으면 $\theta$ 는 두 몫으로 갈린다.

    $$
    \underbrace{\theta_\infty}_{\text{참 분포가 정규선과 이루는 각}} \; + \; \underbrace{O_p(n^{-1/2})}_{\text{표집 잡음}}.
    $$

    따라서 $1 - W \approx \sin^2\theta_\infty + O_p(n^{-1})$ 이고, 앞의 몫만이 "자료가 실제로 얼마나 벗어났는가"다. 뒤의 몫은 $n$ 에만 달린 잡음이다.

    - A: $n = 30$ 에서 잡음 몫 혼자서 중앙값 $1 - 0.9684 = 0.0316$ 이고 5% 지점까지 가면 $0.0693$ 이다. A 가 보고한 $1 - W = 0.040$ 은 전부 잡음으로 설명된다. 참 이탈 $\sin^2\theta_\infty$ 의 추정값은 사실상 0 이고, 자료는 $\sin^2\theta_\infty = 0$ 과도 $0.06$ 과도 똑같이 잘 맞는다.
    - B: $n = 400$ 에서 잡음 몫의 중앙값은 $1 - 0.99635 = 0.00365$ (연습문제 7 의 표) 다. B 의 $1 - W = 0.010$ 에서 그것을 빼면 $\sin^2\theta_\infty \approx 0.0064$ 가 남는다. 잡음의 폭($5\%$ 지점까지 $0.00711$)보다 큰 체계적 성분이다.

    그러므로 결론은 두 겹이다. 첫째, A 의 작은 $W$ 는 A 의 자료가 더 벗어났다는 증거가 아니다. 둘째, 애초에 **A 의 자료에 대해서는 이탈의 크기를 말할 수 없다**. $n = 30$ 에서 잡음이 $\sin^2\theta_\infty$ 를 $0.07$ 규모로 덮어 버리기 때문이다. 이탈의 크기를 효과 크기로 보고하려면 (연습문제 5 의 권고) 그것을 해상할 만큼 $n$ 이 커야 한다. 작은 표본의 $W$ 는 유의성 판정에도 약하고 효과 크기로도 쓸 수 없다. $\square$

## 정리하며

샤피로–윌크의 **구현과 제약**을 확인했다.

- **`scipy.stats.shapiro(x)` 한 줄이다.** $W$ 통계량과 $p$ 값을 함께 돌려준다.
- **$n\le5000$ 제한이 있다.** 넘으면 경고가 나오거나 $p$ 값이 부정확해지며, 대표본에서는 어차피 검정이 과민하므로 그림으로 판단하는 편이 낫다.
- **$n\ge3$ 이 최소다.** 관측 두 개로는 정규성을 말할 수 없다.
- **$W$ 값 자체를 함께 보고한다.** $p$ 값은 $n$ 에 좌우되지만 $W$ 는 적합의 정도를 직접 재므로, **$W=0.98$ 인데 $p<0.001$ 이면 "크게 벗어나지는 않았으나 표본이 커서 잡혔다"**로 읽을 수 있다.
- **Q-Q 그림과 짝지어 쓴다.** $W$ 가 그림의 직선 적합도에 대응하므로 해석이 자연스럽다.
